# 无尽回廊

> 一部可玩的后室探险叙事 · 第一人称中篇
>
> 主角：林屿，二十六岁，前室一名再普通不过的城市物流分拣员。一次意外的 no-clip（滑出现实），把他丢进了那张著名照片里——泛黄的墙、潮湿的地毯、永不停歇的荧光灯嗡鸣。
>
> 这是他从 Level 0 一路向下的记录。读这本书的时候，请把自己当成他。每一章章首的小框，就是你此刻的"存档点"。

---

## 第〇章 · 滑出去

那天我加完夜班，走的是公司仓库 B 区最里头那条几乎没人用的过道。

我记得很清楚，我踩到了一块松动的地砖，整个人往前一栽。

接下来发生的事，没有任何科学能解释。我没有摔在地上。我**穿过**了地面——不是掉下去，而是像穿过一层水帘那样，"刺啦"一声，世界的颜色全变了。

潮气、霉味、还有一种说不出的咸——像盐水，又像福尔马林——一下子灌进鼻腔。我趴在地上，手底下不是水泥，是浸得发软的地毯。

我抬起头。

无穷无尽的黄。

## 第一章 · 黄房间

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 0（阈界 / 黄房间）             │
│  危险等级：Class 1（孤立致死，无确认实体）       │
│  关键物品：—（本层几乎无补给）                  │
│  生存要点：选定一个方向，绝不回头                │
└──────────────────────────────────────────────┘
```

泛黄的墙纸，一直延伸到视线的尽头。潮湿发霉的地毯，踩上去会渗出深色的水。头顶是一排排办公楼那种长条荧光灯，发出持续的、低频的嗡——嗡——嗡，像有一只巨大的虫子贴在你的耳膜上，永远不肯走。

我喊了一声"有人吗"。

没有回音。声音被这无穷无尽的房间吃掉了，连一点点回响都没剩下。

我第一反应是找出口。我穿过一个门洞，是一模一样的黄房间。再穿过一个，还是。我回头想找来时的路——

来时的路不见了。

后来我才知道这叫**边缘移位**（Peripheral Shift）：只要没人看着，这地方的布局就会悄悄重排。你走过的路，回头时已经不是原来那条了。这就是为什么后来遇到的每一个老手都反复念叨那句话：**选一个方向，咬死了走，绝不折返。**

我不知道走了多久。这里没有白天黑夜，荧光灯永远亮着。饿、渴、还有一种比饿和渴更可怕的东西——**孤独**正在啃我。我开始听见声音。墙后面有抓挠声。远处有人在低声说话，像是我妈，又像是个我不认识的人在念一种我听不懂的语言。

我差点就朝那个声音走过去了。

是一个直觉拦住了我。后来 M.E.G. 的人证实了这直觉是对的：**Level 0 里所有"像是另一个人"的声音和身影，都不是人。** 官方判定这里没有已确认的实体，但那些声音会把你引向更糟的地方——比如那种互不相连的死循环回廊，他们管那叫**红房间**（Red Rooms），墙是红的，进去就出不来，人会在幽闭和偏执里疯掉。我远远瞥见过一片泛红的光，立刻掉头朝相反方向走。

我也经过了一片**黑暗区**（Blackout Zone）：照明全灭，积液没过脚踝，地形在脚下高速移动，我连自己的手都看不见。我记着一条不知从哪来的念头——**朝光、朝嗡鸣声冲**——闭着眼往灯光最亮、嗡鸣最响的方向狂奔，直到重新踩到干一点的地毯，灯光重新刺进眼睛。

我饿得开始幻视。余光里有昆虫状的东西爬过墙角，回头看又什么都没有。我蹲下来，差点去揪地毯的纤维往嘴里塞——又一个直觉把我拽住：**别吃地毯，别喝可疑的水。**

我不知道自己撑了几天。可能是三天，可能是更久。直到我看见了它。

一面墙在**闪**。

不是灯的闪。是墙本身，像信号不好的老电视，一阵一阵地泛白、扭曲。我后来知道，那叫**闪烁的墙**（Flickering Wall），是 Level 0 公认的、基本上唯一的有效出口。

我已经没有犹豫的力气了。我后退两步，用尽全身最后一点力气，朝那面闪烁的墙撞了过去。

又是那种穿过水帘的"刺啦"声。

黄色没了。

## 第二章 · 宜居地带

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 1（宜居地带 / Habitable Zone）  │
│  危险等级：Class 1（稳定，但实体中到高）         │
│  关键物品：杏仁水（Almond Water）· 撬棍 · 毛线   │
│  生存要点：闪烁来临沿墙退入走廊——绝对不要跑      │
│  首次接触：M.E.G. α 基地                         │
└──────────────────────────────────────────────┘
```

我摔进了一个完全不同的世界。

无穷无尽的混凝土立柱，像地下停车场和废弃大仓库拼在一起，墙面褪了色，绵延到看不见的地方。头顶交错着管线，地上有来路不明的水洼。这里也安静，但不是 Level 0 那种把声音吃掉的死寂——这里偶尔会有远处传来的、像是有人活动的回响。

第一件救我命的东西，就在十几米外的一个混凝土柱脚下：一个一英尺高、磨得有点旧的**金属保温瓶**。

我拧开盖子，闻到一股甜杏仁混着香草、还带点玫瑰水的味道。我后来才知道这就是后室里最重要的东西——**杏仁水**（Almond Water，Object 1）。它看起来像水，但喝下去不只是解渴：我能感觉到脑子里那团因为饥饿和孤独而起的雾，肉眼可见地散开了。一瓶大概六百卡，一天三瓶就够一个成年人活着。

> 后来一个老手教我认它的颜色：**灰色**最常见、营养最高；**绿色**最甜、提神但喝多了失眠成瘾；**红色**发苦、能当抗生素、是治"疫疾"唯一的法子；**蓝色**助眠抗焦虑、还能挡住精神干扰。
>
> 还有三条铁律，他说不记住会死：
> 一，**绝不喝半空的瓶子**——可能被人动过手脚。
> 二，拿不准的，**煮沸**——有些层级的杏仁水会让你像中了氰化物一样毒发，但煮开就能中和。
> 三，**当心一种叫"液态痛苦"的东西，它会伪装成杏仁水**，实际上是强酸。

我捧着那瓶救命水，第一次有力气好好打量四周。这里被分成几个区段，老手们叫它们天鹰段、镀金段、哥特段……我误打误撞进的是天鹰段。

然后，灯灭了。

全灭。一瞬间，整层楼陷入黑暗。

我后来知道这叫**闪烁**（Flickering）：随机的全层停电，所有灯同时熄灭，而那些敌对的东西，就趁这个时候出来打猎。

我的第一反应当然是跑。我撒腿就要冲——

"**别跑！**"

一只手从黑暗里死死攥住我的手腕。一个压得极低的女声贴着我耳朵："这层是非欧的，你跑只会把自己送到它们嘴边。沿墙，跟着绿色的出口灯，慢慢退进走廊。一步一步。别出声。"

我能听见黑暗里有动静。某种沉重的、贴着地面拖行的声音。还有——一种黏湿的、像很多条腿同时落地的窸窣。那是**肢团**（Clumps），由很多人的肢体扭结成一团的东西，专在走廊里伏击。

我们贴着冰冷的墙，一寸一寸往那点微弱的绿光挪。我的心跳大得我怕它会暴露我们。终于，我们闪进了一条狭窄昏暗的走廊——非欧几何在这里消失了，墙是规规矩矩的墙。

灯重新亮起来的时候，我才看清救我的人。

她穿着拼凑起来的装备，胸口别着一个手绘的徽章。"我叫阿芮，"她说，"M.E.G.，主要探索者集团。欢迎来到后室，新来的。看你这样子，刚从零层爬上来的吧。能活着撞穿那面墙，你已经比八成五的人走运了。"

她带我去了**α 基地**（Base Alpha）——M.E.G. 在天鹰段最大的定居点，由一片走廊改造，用家具堵着门（"别上永久锁，"她说，"锁会消失"）。基地里有几十号人，有人在分拣板条箱里翻出来的食物、绷带、工具，有人在墙上用毛线画地图。

"记住四件事，"阿芮把一根撬棍和一团毛线塞给我，"第一，永远先找杏仁水。第二，进新层级先做 **C.L.I.P.P.**——看威胁、找出口、查数据库认层级、备装备、划安全区。第三，毛线是你的命，像走迷宫那样一路系着标记你的路。第四——"

她顿了一下，声音冷下来。

"**别开枪。** 枪声会把这一整层的实体都招来。"

我在 α 基地待了好几天，缓过了元气，学了怎么认实体。阿芮给我看了一本翻烂了的手册，上面记着这层常见的杀手：趋光的**笑魇**、能穿墙伏击的**钝人**、披着人皮混进人群的**窃皮者**……

"窃皮者最阴，"阿芮指着那一页，"它穿着别人的皮，看起来跟真人一模一样。记住这句口诀——**血色为红，此人尚生；血若清透，切莫近身。** 它的血是透明的。还有，它几乎不说话，或者只会机械地重复几个词。宁可多疑，先验血再信任。"

那时候我还以为这只是吓唬新人的话。

直到第三天，基地外巡逻回来一个人，说自己掉了队、刚找回来。他不太说话，问他什么都只是慢慢地、重复地点头，嘴里念叨着同一个词。阿芮的脸一下子白了。她不动声色地走过去，借口看伤，用刀尖在那人手臂上划了一道。

渗出来的血，是清的。

后面的事我不想细说。基地的人很专业，把它处理掉了，没有一个人受伤。但那天晚上我盯着自己手心的血看了很久，确认它是红的。

阿芮要带一支小队往下走，去 Level 2 找一批掉队的人，再继续往深处探。她问我要不要跟。

我本可以留在 α 基地。它安全，有补给，有人。

但我想回家。而 M.E.G. 的终极目标，就是找到离开后室、回到前厅的出口。跟着他们，是我唯一的机会。

我说，我跟。

我们沿着走廊一路走，管线越来越多，墙上开始出现各种仪表。阿芮说，这就是过渡的征兆——前面，就是 Level 2 了。

## 第三章 · 管道梦境

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 2（废弃公共带 / Pipe Dreams）   │
│  危险等级：Class 3（实体多，含极危）             │
│  关键物品：杏仁水 · 撬棍 · 火柴 · 紫色应急灯标记  │
│  生存要点：欧氏隧道，45° 转折；别盲目开金属门     │
│  威胁升级：笑魇（趋暗）· 肢团（走廊伏击）         │
└──────────────────────────────────────────────┘
```

Level 2 是另一种地狱。

不再有 Level 1 那种开阔的仓库。这里是无穷无尽、布满管道的狭窄隧道，闷热、肮脏、机械密布。墙是腐朽积灰的混凝土和砖，泥棕色，一碰就在手上留下一层残渣。所有通道都以四十五度角转折，长度总是五米的整数倍——这是这一层唯一让人安心的规律：它是**欧几里得**的。距离是真的距离，方向是真的方向。在非欧的后室里，这种"正常"反而珍贵得让人想哭。

但这里的照明稀疏又不均，白光橙光的荧光灯频繁闪烁，到处是大片大片的黑暗区。

"这层 2016 到 2018 出过一次大停电，"阿芮压低声音，带我们贴着一排紫色的应急灯走，"整层供电瘫了，人差不多走光了。现在只有这些紫灯标着还能走的路。**完全黑的地方别进。** 笑魇和肢团全聚在那儿。"

笑魇——**Entity 3**——我那天晚上就见到了。

我们在一个岔路口休整，我背靠着墙打盹。是阿芮把我推醒的，她的手指竖在唇上，眼睛死死盯着我身后那条漆黑的支道。

我慢慢转过头。

黑暗的深处，悬着一张**脸**。

不，不是脸。是一排发着白光的、长得不可能的尖牙，弯成一个巨大的笑容，上面浮着两只发光的眼睛。身体完全看不见，融在黑里。它就那么挂在半空中，对着我笑。

"别眨眼，"阿芮的声音轻得像呼吸，"别背对它，别跑，别出声。盯着它的眼睛，慢慢往后退。"

> 笑魇的设定在不同版本里是反着的：经典版里它**趋光**，你一开手电它就扑过来；新版里它反而**怕光怕火**。阿芮信的是经典那套——这片黑暗区里，开灯等于自杀。她让我们关掉一切光源，靠那点紫色应急灯,跟它干瞪眼。

我们四个人，背贴着背，眼睛全程钉在那张笑脸上，一步、一步、一步地往紫灯的方向退。它跟着我们浮动了一小段，那排牙齿在黑暗里忽明忽暗。然后，在我们退进紫灯照亮的区域那一刻，它停住了，慢慢沉回黑暗里，消失了。

我整个人抖得像筛糠。阿芮塞给我半瓶……不对，是一整瓶蓝色的杏仁水。"喝了，"她说，"压惊，还能挡住它们留下的精神干扰。蓝色的，别喝上瘾。"

我们在 Level 2 里走了两天。这层到处是上锁的金属门，阿芮一扇都不让碰："很多门后面是虚空房间。开错一扇，人就没了。"我们只走没标记的、紫灯指过的门。

队里的一个人——我们叫他老周——脚崴了，走得越来越慢。我们在一个相对安全的管道交叉口扎了营。那天夜里（如果黑暗里还分得出夜里的话），我被一阵低吼惊醒。

不是笑魇。笑魇不出声。

是**吼声**。低沉的、从喉咙深处碾出来的吼。

阿芮一下子坐起来，脸色比见到窃皮者那次还难看："**猎犬。**"

## 第四章 · 发电站

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 3（发电站 / Electrical Station）│
│  危险等级：Class 4（机械自燃 · 毒黑黏液）         │
│  关键物品：火盐（Firesalt）· 杏仁水 · 全后室最强WiFi│
│  生存要点：远离管道黑黏液，提防自燃机械           │
│  威胁：猎犬（Entity 8，跑不过它，瞪住它）         │
│  转折：M.E.G. γ 基地 ⇄ 组织间冲突               │
└──────────────────────────────────────────────┘
```

**猎犬**——**Entity 8**——是后室里跑得最快的猎食者之一。

它四足着地，瘦得能看见肋骨，头上是长而黑的毛，一张嘴布满刀刃一样的尖牙。它没有理智，看见活的就咬。最要命的是它有四条腿——你**跑不过它**。

"听到吼声第一件事不是跑，"阿芮把我们往一道铁栏门里塞，"是躲，是脱离它的视线。它看见你你才完。林屿，把老周架上，进去，别出声。"

那道铁栏后面，是一段往下倾斜的通道。空气一下子变热，一股工业的、铜锈和机油的气味扑面而来。墙是布满灰尘的棕砖，配着铜管和机器零件，地上是覆灰的灰瓷砖，天花板全是金属。某些机器在自己运转，时不时蹦出火花。

我们误打误撞，撞进了 **Level 3——发电站**。

身后传来猎犬撞在铁栏上的声音，还有那张嘴啃咬金属的刺耳尖响。但它没追进来——也许是这层的热和毒气它也不喜欢。

我们活下来了。但 Level 3 是 **Class 4**，比之前所有层都凶险。

阿芮反复警告：管道里流的是**黑色的黏稠液体**，有神经毒，蒸气能致命、能烧伤，**绝对不能碰、不能吸**。还有那些自己运转的机械，随时可能自燃爆炸，靠近冒火花的设备就是找死。这层估计有三亿五千万平方英里，局部热点能烤到五十多度。

但 Level 3 也有别处没有的东西。

阿芮掏出一个旧手机，举起来。屏幕角上，**信号是满的**。

"全后室最强的 WiFi 就在这层，"她笑了，是我认识她以来第一次真正的笑，"M.E.G. 的数据库、通讯，全靠它。所以最强的武装基地——**γ 基地**——也在这。三百号特工，全后室火力最猛的地方。我们去那补给、疗伤，再做下一步打算。"

γ 基地建在一片相对凉爽、机械停转的区域，外面架着用废金属焊的工事。三百号人，荷枪实弹。这里还驻着别的组织——B.N.T.G.，后室不结盟贸易集团，一群只认报酬和以物易物的商人雇佣兵，守着一片存储设施做生意；他们用一种叫"压制币"的自有货币，格言是"以繁荣求和平"。我用阿芮匀给我的两瓶灰色杏仁水，从一个 B.N.T.G. 商人那换了一小袋**火盐**（Firesalt）。

> 火盐——**Object 15**——熔点很低，化开就是"火油"，是对付笑魇这类怕火的实体的武器，也能当热源、当燃料、快速煮沸可疑的杏仁水。在往深处走之前，这东西能保命。

老周在 γ 基地的医疗点养脚。我以为我们能喘口气。

我错了。

我们到的第三天，基地里气氛骤然紧张起来。我从断断续续的对话里拼出了事情的轮廓：M.E.G. 和一个叫"叛乱组织"（The Insurrection）的派系，为了争夺包括 Level 3 在内的地盘，已经**处于战争状态**。而 Level 3 这个补给和通讯的命脉，正是双方都想咬死的肥肉。

那天夜里，警报响了。基地外围的工事方向传来枪声——我第一次听见后室里有人开枪，那声音在金属天花板下回荡，刺耳得让人头皮发麻。我亲眼看着 γ 基地的武装小队冲出去防守。我也亲眼看着，远处一片黑暗里，被枪声招来的笑魇的牙齿，一排一排地亮了起来。

人和人在打仗，而怪物在两边的缝隙里大快朵颐。

阿芮把我和老周拽到一边，神色前所未有地凝重："这地方守不住几天了，两边都在往里调人。补给线一断，γ 基地就成了绞肉机。我们不能等。"

"往哪走？"我问。

她调出数据库，手指在那块满格信号的屏幕上划过一连串层级编号，最后停在一个地方。

"往下。Level 4 是这附近最安全的中转站，从那能去 Level 5。我听过一个传说——很少有人信，但我信。后室里有那么几个极罕见的'出口层级'，能真的把人送回前厅。其中一个的代号是……**3999**。"

她抬起头看我："你不是想回家吗？"

我们趁夜，从发电室深处一部还能用的电梯撤离。电梯门合上的那一刻，我听见外面又是一串枪声，和一声不属于任何人类的、漫长的吼叫。

## 第五章 · 废弃办公室

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 4（废弃办公室 / Abandoned Office）│
│  危险等级：Class 1（最安全宜居之一）             │
│  关键物品：免费杏仁水（冷水器/售货机/喷水池）     │
│  生存要点：避开未涂黑的窗户——那是陷阱           │
│  实体：仅两种——猎犬 · 钝人                      │
│  据点：M.E.G. Ω 基地                            │
└──────────────────────────────────────────────┘
```

电梯门开，我以为自己会再次坠入黑暗。

结果迎接我的，是**明亮**。

一座空置的办公大楼，几乎没有家具，干净、宽敞、结构稳稳当当。窗户大多被涂成了黑色。荧光灯不再恶意地嗡鸣，只是安静地亮着。

我差点哭出来。

**Level 4——废弃办公室**，是后室里最安全、最宜居的层级之一。**Class 1**。实体只有两种——猎犬和钝人——而且数量都不多。最妙的是，这里到处是杏仁水：冷水器、自动售货机，甚至还有储着杏仁水的喷水池。我们终于能放开手脚补给了。

"在这囤够东西，"阿芮说，"这是进深层前最后的天堂。"

但即便这里也有它的陷阱。阿芮指着远处一扇没被涂黑的窗户，那是整片黑窗里唯一透着光的一扇："**绝对别靠近没涂黑的窗户，别往外看。** 那是陷阱。涂黑的窗安全，透光的窗要命。"

我们在 Level 4 的 **Ω 基地**休整了几天。Ω 基地驻着 M.E.G. 差不多一半的小队，靠近通往 Level 5、6 的入口。在这里，我第一次见到了那种东西——一开始我以为是基地里的居民。

一个孩子，在走廊尽头蹲着，背对着我们玩什么东西。

我下意识想过去——又是阿芮拦住了我。她没有惊慌，反而把声音放得很轻很柔。"那是**无面人**（Faceling，Entity 9），"她说，"看见没有，它没有脸。"

那"孩子"转过身。它有头发、有衣服、有手有脚，体型和真的孩子一模一样——但从额头到下巴，是一整片光滑的、没有任何五官的空白。

"它们大多温顺，"阿芮慢慢蹲下，和它平视，"它们在模仿人——上班、过节、谈恋爱、收养孩子。它们不是怪物。但是——"她特意加重了语气，"千万别招惹、别嘲笑、别做出威胁的姿态。尤其是**孩童无面人**，最不稳定，一点点刺激就会暴怒。要是它身边有大人无面人在守着，那更碰不得。"

那孩子歪着没有脸的脑袋"看"了我们一会儿——它没有眼睛，却像看得见一样——然后又转回去，继续玩它的东西。阿芮带着我们安静地、不做任何突然动作地绕了过去。

那天晚上，我躺在 Ω 基地一间安静的办公室里，听着远处看不见的无面人在过它们模仿来的"日子"，第一次睡了个不被噩梦劈开的觉。

第二天，我们找到了通往 Level 5 的那道老办公楼楼梯。阿芮说，Level 3999 的传说里，路要先经过几个层级的中转。Level 5 是绕不过去的一站。

"Level 5 漂亮，"她在楼梯口顿住，回头看我，眼神复杂，"漂亮得过分。记住——后室里越漂亮的地方，越要命。"

## 第六章 · 恐怖旅馆

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 5（恐怖旅馆 / Terror Hotel）    │
│  危险等级：Class 2（美丽与死亡并存）             │
│  关键物品：火盐 · 杏仁水 · 一双不出声的鞋        │
│  生存要点：环境自清洁；爵士乐永不停              │
│  威胁：死亡飞蛾巢穴 · 窃皮者 · 观察者            │
│  出口线索：贝弗莉室的"低概率出口"               │
└──────────────────────────────────────────────┘
```

楼梯尽头，是另一个世界。

一座近乎无限的酒店，建筑风格停在一九二零、三零年代——华丽的金色壁纸，铺着不同材质的地板，水晶灯，一尘不染。空气里飘着老唱片机放出来的爵士乐，醇厚、温柔、缠绵不绝。

它干净得不真实。我看见一滩我们带进来的泥脚印，在几分钟里**自己消失了**——这层会自我清洁。

"Level 5，恐怖旅馆，"阿芮说，"Class 2。这里有友善的住户社群，也有……别的东西。"

"别的东西"很快就让我们见识到了。

我们经过一道虚掩的房门，里面传来一阵细密的、翅膀振动的声音。阿芮一把把我们按在墙上，比了个噤声的手势，指了指门缝。

门缝里，是密密麻麻、层层叠叠的飞蛾。不是普通的飞蛾——它们大得反常，趋光，那间房就是它们的**巢穴**。**死亡飞蛾**（Death Moths）。Level 5 是它们在后室的核心巢穴之一。我们灭掉了手里所有的光源，屏住呼吸，贴着对面的墙根，一寸一寸地挪了过去。其中一只受惊飞起，撞在水晶灯上，我的心脏几乎停跳——但它没有追出来。

我们要找的是**贝弗莉室**（Beverly Room）——一间被称作"永恒舞厅"的地方，里面有数百扇门、一局没下完的麻将，传说中藏着一个**低概率的出口**。阿芮的数据库里记着，从那里有极小的几率，能踏上通往 Level 3999 那条路的起点。

找贝弗莉室的过程，是我整段旅程里最磨人的。这层的走廊会绕，爵士乐从四面八方钻进来，让人分不清方向。我们结伴走，互相验过血——红的，都还是人。在一条挂满油画的长廊里，我感觉到一种被注视的感觉，毛骨悚然。阿芮说那可能是**观察者**（The Watcher），让我们别回头看，加快脚步。

终于，我们推开了那扇门。

贝弗莉室是一个巨大到看不见尽头的舞厅，地板光可鉴人，四面墙上密密麻麻全是门——数百扇，每一扇都一模一样。中央一张桌子上，摆着一局下到一半的麻将，牌面落满了灰，仿佛对弈的人刚刚起身，又仿佛他们离开已是一个世纪以前。

"出口就在这数百扇门里的某一扇，"阿芮的声音在空旷的舞厅里荡开，"概率很低。我们只能一扇一扇试。但是——"

她的话被打断了。

舞厅的另一头，灯光昏暗的角落里，站着三个人。

他们穿着拼凑的装备，但没有任何徽章。其中一个开口，声音平板、机械，**重复着同一个词**，一遍又一遍，不带任何含义。

阿芮的手立刻按上了腰间。"别动，"她对我们说，眼睛盯着那三个"人","谁能说句完整的话？报上你们的队。"

那三个"人"没有回答。他们只是慢慢地、一致地，朝我们走过来。其中一个的步态有点不对劲，僵硬，像在模仿走路。

阿芮抓起桌上一只麻将牌，狠狠掷过去，砸在最前面那个的脸上。

破开的皮肤下，渗出的血是**清的**。

"**窃皮者！**"她吼道，"林屿，老周，背靠背！别落单！"

三个**窃皮者**（Entity 10）扑了上来。我这才明白阿芮为什么一路逼我们记那句口诀——血色为红，此人尚生；血若清透，切莫近身。它们力大得吓人，伪装态下漫无目的，可一旦进入饥饿态，就会徒手把人撕碎剥皮。

我们靠着背，挥着撬棍往后退。阿芮抓住一个空当，划着了火盐——化开的火油"轰"地窜起一片火光。窃皮者怕火，那三个东西在火光里迟疑了一瞬。

就是这一瞬。

老周——那个崴了脚、一路被我们架着走的老周——拼着一口气，撞开了离我们最近的一扇门。

门后不是虚空。门后泛着柔和的、流动的霓虹光。

"这扇！"他喊，"是这扇！"

我们三个，连滚带爬地冲了进去，阿芮殿后，反手又甩出一团火油挡住追来的窃皮者。门在我们身后"砰"地合上。

霓虹的光，温柔地把我们包了起来。

## 第七章 · 真结局

```
┌──────────────────────────────────────────────┐
│  当前层级：Level 3999（真结局 / 霓虹街机厅）      │
│  危险等级：Class 0（完全安全 · 无任何实体）       │
│  关键物品：任意硬币状物 · 票券（密码：931）       │
│  生存要点：不用战斗、不用逃跑——只需走对流程      │
│  终极意义：后室极少数能真正回到前厅的出口之一     │
└──────────────────────────────────────────────┘
```

我用了很久，才接受眼前这一切是真的。

一座看似无限的、被遗弃的复古街机厅，混着老影院的气味。霓虹灯沿着墙壁铺开，红的、蓝的、紫的，柔和地流动。一排一排的街机静静立着，屏幕上滚动着八十年代的像素画面。

没有嗡鸣。没有黑暗。没有牙齿，没有吼声，没有没有脸的孩子。

**Class 0。完全安全。没有任何实体，没有任何异常物体。**

我能感觉到——那种自从坠入 Level 0 起就一直压在我脑子上的、后室的精神重负，在这里第一次彻底松开了。阿芮说，这是这层的特性：只要你沉浸在游戏里，后室在你身上留下的所有负面精神效应，都会被缓解。

这就是传说中的 **Level 3999——真结局**。后室里极少数、极少数能真正把人送回前厅的"出口层级"之一。

我们顺着废弃的街机大厅一直往里走，走到尽头一间小小的街机厅。右上角有张桌子，桌上放着一张票券，褪了色，上面印着一个数字：

**931。**

小厅的角落里，有一部需要密码的电梯。

阿芮把那个数字按了进去。电梯门开了，里面的天花板上嵌着一台老电视，开始播放一段 M.E.G. 制作的科普影像——讲穿墙 no-clip 是怎么回事，讲那些回归现实的机制。阿芮按住我的手："别跳过，"她说，"同一个人只能看一次，里面有真东西。"

看完影像，电梯缓缓启动。

就在那一刻，我才反应过来一件事——

电梯只够送一个人回去这一程的"流程"，剩下的人要留下来引导下一批、维护这条出口。这是 M.E.G. 一直在做的事：他们不只是探索者，他们是**守门人**。

阿芮看着我，笑了。还是我第一次见她笑时那个表情。

"林屿，"她说，"前面那道玻璃门，走过去就是家。你的家。"

我看着那道门。门外，是我离开了不知道多少天、多少个永不天黑的夜晚的——现实。仓库 B 区那条没人用的过道，加班的夜，平淡到我从前嫌它无聊的一切。

我也看着阿芮，看着架着拐、还在喘的老周，看着这座把无数希望和绝望都收容进来的、霓虹色的房间。

"那你们呢？"我问。

"我们?"阿芮耸耸肩，把腰间最后一团火盐塞到我手里，又收了回去——"算了，前厅用不上这个。"她拍了拍我的肩，"我们回 α 基地。还有人困在零层，在管道里，在那座要塌的发电站里。总得有人去接他们。"

"总得有人，"老周重复了一遍，咧嘴一笑，这次他的话是完整的，他的血我亲眼见过，是红的，"总得有人守着这扇门。"

我站在玻璃门前，回了好长一段路的头。

然后我推开了门。

## 尾声 · 前厅

"刺啦"一声。

潮气、霉味、咸味，全没了。空气里是熟悉的、廉价的水泥灰和机油味。

我趴在仓库 B 区那条过道的地砖上。那块松动的地砖还在原地。头顶是规规矩矩的、不会发出恶意嗡鸣的日光灯。

监控记录显示，我只"消失"了四十多分钟。

没有人会相信我。我也不打算让任何人相信。

但有些事变了。

我书桌的抽屉里，一直放着一个一英尺高、磨得有点旧的金属保温瓶——我下意识地从 Level 4 的喷水池里灌满、一路带回来的，灰色的那种。它现在是空的，气化后不留一点残留，就像它从没在那个世界里救过我的命一样。

我查过了。**杏仁水**是少数同时存在于现实和后室的东西之一——在前厅，它是一个法国家族的配方，叫维多利亚厨房的欧式饮料。我现在每天都买一瓶。它当然没有任何异常的功效了。

但每次拧开盖子，闻到那股甜杏仁混着香草和玫瑰水的味道，我都会想起阿芮，想起老周，想起那道把我送回家、却把他们留在了无尽回廊里的玻璃门。

我把这一切都写了下来，就是你现在读到的这些。

我写下来，是因为——也许有一天，你也会踩到一块松动的地砖。也许有一天，世界会"刺啦"一声，颜色全变了，你会趴在潮湿的黄色地毯上，听着永不停歇的荧光灯嗡鸣。

如果那一天来了，请记住：

**选一个方向，咬死了走，绝不回头。**

**找到杏仁水。**

**血色为红，此人尚生；血若清透，切莫近身。**

**如果你看见一群胸口别着手绘徽章、彼此叫着希腊字母的人——**

**跟着他们走。**

**他们会带你回家。**
