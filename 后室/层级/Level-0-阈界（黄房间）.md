# Level 0（阈界 / 黄房间，"Threshold" / "教学关卡"）

> 别名：The Yellow Hell（黄色地狱）、The Tutorial Level（教学关卡）、黄房间。
> 后室的第一个层级，也是绝大多数流浪者（Wanderer）"切出"（no-clip）现实后最先到达的地方。

## 概述

Level 0 是后室（The Backrooms）最具标志性的层级，几乎是整个都市传说在 2019 年由 4chan 用户 Bob Mazza 发布的那张原始照片所定格的形象：泛黄的墙纸、潮湿的地毯、嗡嗡作响的荧光灯，一望无际、单调到令人发疯的空旷房间。它是后室文化的"门面"，也是死亡率最高的层级之一——并非因为有实体，而是因为单调、孤立与资源匮乏。

据估计，约 **85% 切出进入后室的人永远走不出 Level 0**。

## 描述与环境

Level 0 是一处**非线性空间**（non-linear space），外观类似零售店或办公楼的后勤储藏区。所有房间共享一组浅表特征，但没有任何两个房间完全相同：

- **泛黄的墙纸**（标志性的"芥末黄/病态黄"色调）。
- **潮湿、发霉的伯柏式（Berber）地毯**，浸透了各种来源不明的液体（盐水、咸水、福尔马林等化合物）。
- **不规律布置的荧光灯**，发出持续的低频嗡鸣，偶尔嗡鸣会骤然增强到足以损伤听力。
- 黄色办公风格的吊顶天花板。

无尽的单调被官方描述为会诱发"恶性谵妄"（malignant delirium）。环境中还存在若干**结构性畸变区**（Wikidot 版本）：

| 畸变区 | 特征 |
|---|---|
| **拱门区（Arches）** | 苍白墙壁上开有拱形孔洞；少数稳定、不会移位的区段。 |
| **柱厅（Pillars）** | 绵延数英里的格栅状巨型房间，地毯很浅。 |
| **坑洞群（Holes/Pits）** | 网格状排布的深坑，深度未知，坠落几乎致命。 |
| **黑暗区（Blackout Zones）** | 完全无照明、地形高速移位、积液没过脚踝的区段，极难穿越也极难逃出。 |
| **红房间（Red Rooms）** | 互不相连的死循环回廊，引发严重幽闭恐惧与偏执，基本无法逃出。 |
| **边缘移位（Peripheral Shift）** | 当无人观察时布局会扭曲重排，使走过的路变得无法辨认。 |

### 噪声

荧光灯嗡鸣、含糊的低语与"熟悉的人声"、墙后传来的抓挠声。这些多被判定为感官剥夺与孤立导致的**幻觉**。

## 生存难度（Survival Difficulty）

| 项目 | 评定 |
|---|---|
| **危险等级（Class）** | Class 1（安全 / Safe，Secure） |
| **实体数量** | 未确认（Unconfirmed Entities，0 已确认） |
| **稳定性** | 稳定（Secure / Stable，但布局会移位） |
| **出口数** | 实质上仅 1 个有效出口方向（切出至 Level 1） |

主要死因是**脱水、饥饿与心理创伤**，而非实体攻击。值得注意的是：尚无在 Level 0 中发现尸体的记录。

## 实体

**官方判定本层不存在已确认的实体。** 任何你确信是"另一个流浪者"的视觉/听觉接触都被警告"那不是人类"。Wikidot 版本提到未经证实的"黑色人形"目击与被注视感（scopophobia），但均归类为幻觉或未确认报告。

### 孤立效应（The Isolation Effect）

两名一起切入的流浪者**无法互相找到**，所有通讯尝试都会失败。唯一的例外是一间罕见的小型**马尼拉色房间（Manila Room）**，在其中双方可以互相看见、作为短暂的休息点，但该房间本身没有出口。

## 入口（Entrances）

- **从现实意外"切出"**（no-clipping）——这是进入 Level 0 最普遍、最统一的方式。
- 后室各处隐藏的入口偶尔通往此处。
- （中文 Wikidot）Level 283 堡垒中一扇散发霉味的木门，极其罕见。

## 出口（Exits）

- **找到一面"闪烁的墙"并撞穿它** → 通往 **Level 1（宜居地带）**。这是公认且基本唯一的有效出口。
- 在黑暗区/移位区随机切出，结果不可控。

## 生存指南与可用物品

- **选定一个方向并坚持走下去**，不要反复折返（边缘移位会让回头路失效）。
- 在黑暗区中**朝着光亮或嗡鸣声冲刺**，尽快脱离。
- **彻底避开红房间。**
- **不要食用地毯纤维，也不要饮用被污染的杏仁水（Almond Water）。**
- 睡觉时**面朝你的前进方向**，醒来不易迷失。
- 荧光灯嗡鸣骤增时**捂住耳朵**以防听力损伤。
- 本层几乎没有可靠补给，长期停留几无可能。

## 轶事与版本差异

- **起源**：基于 2019 年 4chan 的原始后室概念（作者 Bob Mazza）。Wikidot 页面由 u/Deveyerr 改编，后由 DivineAtlas、Robert Goerman、DrAkimoto 等重写。
- **CO₂ 上升**：中文 Wikidot 提到 Level 0 内二氧化碳浓度稳定上升，意义未明。
- **常见幻觉清单**：灯光/噪音变化、门或楼梯凭空出现、既视感（déjà vu）、听到非已知语言的声音、余光中昆虫状物体、昆虫吱吱声。
- **版本差异**：
  - **Wikidot 新版**称 Level 0 为 **"Threshold"（阈界）**，强调结构畸变区与孤立效应。
  - **Fandom 旧版 / 经典版**称 Level 0 为 **"The Lobby"（大堂）**，是最贴近 4chan 原始照片的"纯黄房间"描述。
  - **中文 Wikidot** 译为 **"教学关卡"**。
  - 三版均一致：危险等级 Class 1、无确认实体、出口指向 Level 1。
