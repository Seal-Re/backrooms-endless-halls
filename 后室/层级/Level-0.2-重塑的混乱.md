# Level 0.2（重塑的混乱 / Remodeled Mess）

> 别名：「Remodeled Mess（重塑的混乱 / 改造混乱）」。介于 **Level 0（黄房间 / The Lobby）** 与 **Level 1（宜居区）** 之间的子层级（Sublevel）。

## 概述

**Level 0.2「重塑的混乱」** 是一个由神秘组织「**后室改造公司 / 后室装修公司（Backrooms Remodeling Co.）**」创建的子层级。它的核心设定极具讽刺意味：表面上是 Level 0 的「翻新改良版」——干净、舒适、设施齐全——但一旦被触动，整层就会像多米诺骨牌般连锁崩塌，露出底下未完工的房屋骨架。当破坏链蔓延到返回 Level 0 的门时停止；而一旦重新进入，整层又会完好如初，仿佛什么都没发生。

它是后室中少数把「装修 / 施工 / 烂尾工程」作为恐怖母题的层级，叙事核心围绕一个失职施工队的内部文件展开。

## 描述与环境

- **初始（未触动）状态**：看上去是 Level 0 的彻底翻新版：
  - 干燥的红色地毯；
  - 重新粉刷过的白色墙壁；
  - 持续稳定工作的 Wi-Fi 和电源插座；
  - 偶尔出现的浴室/洗手间。
- **触动后的崩塌**：一旦进入并触及层内任何东西，整层开始解体：
  - 天花板瓷砖坠落；
  - 墙壁倒塌；
  - 地板塌陷，露出**未完工的房屋结构**。
  - 崩塌的碎屑可能砸到流浪者，事后扬起的粉尘也极具危害。
- **恢复机制**：破坏的连锁反应一旦蔓延到通往 Level 0 的门便停止；流浪者重新进入时，整层会**完全修复**，如同从未发生过崩塌。

## 实体

- 页面**未记载任何已知实体**。主要威胁来自环境本身——崩塌的天花板、墙壁、地板碎屑及粉尘。

## 入口（Entrances）

- 在 **Level 0** 中，当头顶灯光的嗡鸣声平息、地毯变干、房间开始呈现「施工中」的样貌时，就有几率找到一扇通往 Level 0.2 的门。

## 出口（Exits）

- 以与进入相同的方式离开：找到一扇门即可返回 **Level 0**。

## 生存指南与可用物品

- **尽量不触动层内物体**，减少触发连锁崩塌的风险；进入后保持靠近返回门的位置，以便崩塌时快速撤离。
- **防范粉尘**：崩塌后扬起的粉尘有害，建议遮挡口鼻。
- **可回收文件（核心彩蛋）**：层内可找到三份与后室改造公司相关的文件：
  1. 公司标语：「True order comes through furniture（真正的秩序源于家具）」；
  2. 一份改造任务委派单，由主管 **Major Took** 指示 **Task Force 102-CX（102-CX 特遣队）** 执行改造任务；
  3. 一封不完整的员工回信，提及工作表现不佳与求情内容。
- **基地/前哨**：无已知基地、前哨或社区。

## 轶事与版本差异

- **后室改造公司之谜**：该组织的动机、Level 0.2 的自毁机制究竟是「故意设计」还是「施工事故/烂尾」，均无定论；回收文件暗示这支特遣队过往工作记录欠佳，呼应了「Remodeled Mess（重塑的混乱）」这一讽刺命名。
- **版本差异**：
  - **Wikidot 版（backrooms-wiki.wikidot.com / 中文站 backrooms-wiki-cn.wikidot.com）**：即本文主要依据，设定一致，定为 Class 3，由后室改造公司创建，无实体。这是较「规范」的权威版本。
  - **英文 Fandom 经典站**：Level 0.2 条目为**空页**（未收录此设定）。
  - **其他衍生 wiki**：在 Freewriting、Redacted、Escape The Backrooms 等站，Level 0.2 有「Danger Zone（危险地带）」「死亡之屋」等完全不同设定（如红橙色调、逐渐破败的 Level 0 变体）——与本「重塑的混乱」版本互不兼容。
