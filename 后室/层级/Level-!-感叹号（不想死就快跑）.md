# Level !（感叹号 / 不想死就快跑 / Level Run）

> 别名：「不想死就快跑！」（Run For Your Life!）、「Level Run」、单纯一个「跑」字。在引入卡斯帕-布雷编号系统（Casper-Bray Numbering System, CBNS）前曾被称作 **Area - 847**。

## 概述

**Level !（感叹号）** 是后室（The Backrooms）中最危险、最具传奇色彩的异常楼层（Anomalous Level）之一。它的名字不是数字，而是一个红色的感叹号——这本身就标记了它在体系中的特殊地位：它是少数以符号而非数字命名的层级之一，且**只能进入一次**。一旦逃离便永远无法再次踏入（极罕见的二次进入除外），因此人类对它的了解始终十分有限。

其核心玩法（lore 设定）极为鲜明：进入即触发警报，海量实体从被锁的门后破门而出，流浪者（Wanderer）必须不眠不休地跑完约 **10 公里**长的医院式血红走廊才能逃生。它被视为「后室对人类追逐恐惧的集中体现」。

## 描述与环境

- **入口房间（病房）**：抵达后，流浪者通常出现在一个被血红色光芒笼罩的病房中。陈设简单：中央一张铺着整齐被子的病床，旁边的桌子摆放基础物资，床边有窗帘，角落是一个存放药品的药柜。
- **走廊（主舞台）**：离开病房后进入长达 **10 公里**的走廊，外观类似现代医院走廊。
  - 天花板上随意排布着「EXIT」出口标志，其发出的暗红色光被认为是楼层唯一光源——因此有的区域过度明亮、有的完全漆黑。
  - 未知来源的**警报声**持续不断地在楼层内鸣响，声音极大，会损害流浪者精神状态，使其无法理性思考。有人认为警报是心理作用，未经证实。
  - 走廊两侧的门由**不可摧毁的未知金属**构成，大多无法打开；能打开的门通向房间（进去后几乎无法再离开，且可能藏有实体）。
  - 地面、墙壁、天花板均**不稳定**，会出现裂缝并坍塌；天花板坠落时可能垂下危险电线（绊倒或电击）。
- **安全区（Safe Zone）**：罕见的休息区，色调以蓝色为主、光照充足，没有任何实体。两侧门后房间有架子和床，可找到杏仁水、能量棒。**仅 6% 的已证实报告提到曾遇到该区域。**

## 生存难度（Survival Difficulty）

| 项目 | 评级 |
| --- | --- |
| **危险等级（Class）** | **Class 5** |
| **逃脱指数** | 4/5（极难逃脱） |
| **环境指数** | 5/5（死区 / Deadzone） |
| **实体指数** | 5/5（敌对实体侵占） |
| **稳定性** | 极不稳定（地面/墙壁/天花板随时坍塌，出口标志可能爆炸） |
| **出口数** | 实质上仅 **1 个真正的出口**（走廊尽头），但途中遍布**假出口（Fake Exits）** |

> 总体定性：后室中最危险的异常楼层之一，「任何人都不应以任何理由进入」。

## 实体

走廊中的实体「复杂多样，几乎涵盖了后室所有的实体」，且诡异的是这些实体的**移动速度几乎完全一致**。已点名出现者：

- **死亡飞蛾（Death Moths）**：成群从头顶袭击；不太聪明，可用扔水瓶等物品转移其注意力。
- **笑魇 / 微笑梦魇（Smilers）**：Level ! 内最大的威胁，怕火怕光；可用手电筒阻止其出门，离得太远它们会失去兴趣，可射击出口标志（生火）驱赶。
- **派对客（Partygoers）**
- **曼布里蜘蛛（Manbrids / Wretches）**
- **窃皮者（Skin-Stealers）**
- **悲尸（Dullers）**
- **猎犬 / 嗜血猎犬（Hounds / Clumps）**：聪明，喜爱光明，可射击光源使其迷惑。

实体既会从破开的锁门追来，也会从两侧门或天花板通风管道中突然冒出（后者多为体型小或可变形的实体，速度较慢，多起威慑作用）。

## 入口（Entrances）

主要有两种进入方式，外加若干特殊入口：

1. **格格不入的出口门**：在任意楼层随机出现、位置不断变化的一扇与环境不协调的「EXIT」门。进入后门立即关闭，转身可见门后印着巨大的红色感叹号。
2. **与感叹号有关的元素**：例如卡入与感叹号有关的物体；或走入门上印有感叹号的电梯，再次开门时已身处 Level !。
3. **特殊入口**：
   - 在 **Level @（绝对真空 / 虚惊一场，原文为「虚惊一场」语境）** 内产生某种特定想法。
   - 卡入 **Level 2** 的地板。
   - 多名流浪者同时进入时，会被强制分开。

> **关于感叹号的诡异现象**：在 Area - 847 改名为 Level ! 之前，没有人通过「与感叹号有关的元素」进入过；通过出口门进入者也都声称没在门后看到红色感叹号。这暗示后室可能与人类思想息息相关，是对「随机论」的有力反驳。

## 出口（Exits）

- 跑完约 **10 公里**后抵达走廊尽头的出口门。**若两侧没有其他岔路走廊，那才是真出口**。
- **假出口**遍布全程：每隔几公里出现的弯道会制造「到达出口」的假象，假出口的标志通常较暗，多通向空房间（导致被实体抓住），或让流浪者重新进入 Level !。
- 真出口通常通向较安全楼层，生存难度多为 **Class 宜居、Class 0、Class 1**，其中 **Level 1** 和 **Level 4** 最常见（出口前曾描述一道「蓝色的门」通向蓝色安全走廊 / 仓库式场景）。
- 离开后，原出口门会变为入口门；**一旦离开 Level ! 便不会再次进入**，尝试进入入口门只会到达所在楼层的另一地点。极罕见情况下门会让流浪者重回 Level !，能二次逃离者寥寥无几。

## 生存指南与可用物品

探险者总署（M.E.G.）官方生存指南要点：

- **#1 尽快收集物资（但要克制）**：抵达病房后花约 5 秒收集杏仁水、能量棒、手电筒等，留作后期体力透支时的「秘密法宝」；携带过多物资反而拖慢速度、消耗体力。别为搜物资浪费宝贵时间。
- **#2 它们还在附近，别停！**：跑五六公里后实体可能从视野消失、只剩警报声——这是楼层的伎俩，实体并未消失，**绝不能停下休息**（跑跑停停比一直跑更耗体力）。
- **#3 「那里是谁？」——逐一识别实体弱点**：笑魇怕光怕火（手电筒、射击出口标志生火）；死亡飞蛾蠢，可扔水瓶引开；猎犬喜光，可射击光源迷惑。
- **#4 在安全区慢慢来**：遇到蓝色安全区应至少休息几小时到一天（最多两三天，食物有限）以大幅提升存活率，别只待十分钟就走。
- **逃出后保持冷静**：不要立即躺下/坐下（体力达极限后骤停可能猝死），保持慢走慢跑前往最近 M.E.G. 前哨站。

**关键可用物品**：手电筒（黑暗区避障、克制笑魇）、杏仁水、能量棒、可投掷的水瓶（引开死亡飞蛾）。

**罕见威胁事件**：出口标志爆炸引发火墙（爆炸前标志会异常闪烁、发出刺耳嘶嘶声、亮度异常）；两侧门 / 通风管道涌出实体；地面 / 墙壁 / 天花板坍塌；垂落电线。

## 轶事与版本差异

- **编号沿革**：CBNS 系统启用前称 **Area - 847**；因其医院外观与 **Level 14** 相似，一度被归为 Level 14 的亚层（sub-level），并被误编号为 **Level 14.5**。至今仍有人主张它原本是 Level 14 的亚层。
- **首次官方记录「图像E（Image E）」**：发现于 **Level 52** 的一张照片，据信摄于十九世纪；考尔研究组织（Kalag Research Organization）在 Level 52 发现 Jacques Dubois 的日记，疑为拍摄者，但笔迹多已不可辨。也有人认为照片其实拍自 Level 14、Level 16 等相似楼层。
- **M.E.G. 最早记录**：来自成员 **Noah C. Boyle**，他在收集某神性实体（Godly Entity）信息时意外进入并（据公开信息）死于此层；亦有传言称其未死、暗中隶属某组织。
- **复现之谜**：故事框架中，赫兹博士（Dr. Hertz）的讲座引出「Level ! 曾在黑暗侵袭（Darkest Hour / Lights Out 类事件）中被毁，为何又重新出现」的疑问，留作开放悬念（结尾出现「致 Impresario B.」的打字信件与音频日志彩蛋）。
- **理论众说纷纭**：救赎论（罪人受罚、奔跑即洗礼）、大罪论（政府筛选超级士兵）、外星娱乐论（外星人下注观看人类逃生）、考尔理论（Level ! 是「在后室中被追逐的恐惧」的集中体现）、以及 Level 14 亚层论。
- **版本差异**：英文各 Fandom 衍生 wiki（Escape The Backrooms、Backrooms Unlimited、Redacted 等）对走廊长度、出场实体清单（如 Hounds / Skin-Stealers / Facelings）和逃生机制描述略有出入；本文以**后室中文维基（backrooms.fandom.com/zh）**翻译自经典 Fandom 版的条目为准。
