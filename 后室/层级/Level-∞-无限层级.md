# Level ∞（无限层级 / 阈限机场 The Liminal Airport）

> 别名：「The Liminal Airport（阈限机场）」。编号不是数字而是**无限符号「∞」**——这本身就标记了它在体系中「超越一切数字层级」的特殊地位。

## 概述

**Level ∞（无限层级）** 是后室中最危险、最不可预测、也最具「元设定 / 模因」色彩的概念性层级之一。它的编号是无穷大本身，被认为是「后室真正无限、永无逃脱」这一恐怖命题的实体化证据。

其核心形象是一座**无限延伸的机场航站楼（plane terminal）**。它被认为与「埃舍尔阶梯（The Escherian Stairwell）」「电脑实验室（Computer Lab）」「通往虚无之路（Road To Nothingness）」紧密相连，并展现出后室其他区域不具备的诡异性质——包括独立昼夜循环、模因污染、心灵感应幻觉等。

## 描述与环境

- **结构**：一座似乎永远延伸的机场航站楼。
- **窗户**：展示「外部世界」的窗户通常一片空白，**应不惜一切代价避开**，以防触发意外事件。
- **昼夜循环**：本层有自己的昼夜循环；**夜晚时多数窗户会变成紫罗兰色并向外打开**，进入窗户的后果未知（推测会随机传送到别的层级或一个未列出的层级）。
- **夜间危险**：夜晚循环时，**后室中几乎所有已知实体都可能在此出现**。
- **商店与补给**：层内有大量商店，可找到手电筒、电打火机、食物、水等常规商品；但**沿任一方向走约 1 万公里后，店内会越来越空荡荒凉**。
- **不可食用警告**：在此**找不到杏仁水（Almond Water）**；货架上的食物大多不可食用，可能导致严重感染和疾病乃至死亡；餐厅冷冻柜、橱柜、储藏室里的食物同样不安全。
- **幻觉与心灵感应**：久留会产生幻觉（看到挚爱亲友），伴随心灵感应讯息——据信源自一种本层独有、未被记录的模因实体（memetic entity）。
- **室外（跑道）**：可走出航站楼到跑道上，但极不建议——室外几乎无遮蔽，特征与室内相同、向所有地平线无限延伸；飞机自行起降而无人驾驶；**夜间绝不可待在室外**，日落时应立即回室内（找车库或紧急出口）。
- **模因污染**：Level ∞ 对**关于自身的一切文档**有不可阻止的模因效应，会腐化、故障化档案，并夹杂来自某未知种族的密文（与心灵感应/幻觉相关）。文档中曾出现卢恩文（Runic）密语，大意为「没有真正的终结，没有逃脱，只有无尽。无限才是这个现实的真实形态……跟随声音，跟随光，接受你唯一的命运……成为我们的一部分」。

## 实体

实体可出现在层内任何地方，每 3 分钟有 97.6% 几率遇到一个。已记载实体包括：

- **Windows（窗户怪）**
- **Trollgers / Trollges（巨魔脸）**
- **Nextbots**
- **Nightmare（梦魇）**
- **Facelings（无面者）**
- **Smilers（笑魇）**
- **Partygoers（派对客）**
- **Partypoopers（扫兴者）**
- **Deathmoths（死亡飞蛾）**

## 入口（Entrances）

- 从每一个层级（甚至死胡同层级）都有**无限多种**方式进入 Level ∞，仅列出知名几种——核心都是「随机穿墙（random noclipping）」：
  - 在「通过随机穿墙进入的层级」中再随机穿墙；
  - 在任意层级随机穿墙；
  - 在 Level ∞ 自身内随机穿墙。

## 出口（Exits）

**登机离开（核心机制）**：

1. 通过登机桥进入任意一架飞机；
2. 一个完全被白光抹去的人形会迎接你并索要护照——你必须**如实回答它问的所有问题**（无需真的交出护照）；答对则登上下一班航班，答错则极可能在 Level 0 或与之密切相关的层级醒来。
3. 登机后**绝不可与其他人形对视**；飞行时长 15 分钟至 4 小时不等；航班结束时**务必最后一个下机**，否则可能被送往任何 Class 3 及以上或 Class 死区（Deadzone）的层级。
4. **特殊（致命）出口**：若登上一架「在前室坠毁过的航班」，你将以乘客身份重历那场空难——并以**死者**的身份离开后室。已知此处出现过的前室真实空难航班：狮航 610 号班机（Lion Air 610）、日航 123 号班机（JAL 123）、特内里费空难（Tenerife Disaster）。

## 生存指南与可用物品

- **避开所有窗户**（尤其夜间变紫并打开的窗户）。
- **日落即回室内**，绝不在室外过夜。
- **不要吃货架/餐厅的食物**，可能致命感染；此层无杏仁水。
- **登机时如实作答、不与人形对视、最后下机**——这是唯一可靠的逃生流程。
- **可拾取**：手电筒、电打火机（10000 公里内的商店较充足）。
- **基地/社区**：因层级的异常性质（且本层「不喜欢殖民地」，暗示其可能具有感知力 sentient），**无法建立任何社区**。

## 轶事与版本差异

- **「模拟假说」与终极阴谋**：Level ∞ 催生了一种阴谋论——后室（乃至现实）可能是某种「模拟（simulation）」，且后室真正无限、无路可逃；「The End（终焉）」与「The Beginning（起源）」两个层级的存在被用来佐证此说。
- **与 9223372036854775807 的关系**：尚不清楚 Level ∞ 在 Level 9223372036854775807（int64 上限 / 无限阶梯）之上还是之下，也不清楚它为何编号会是无穷大本身——两者同属「概念性终极层级」。
- **版本差异**：
  - **Wikidot 经典版 / Freewriting 转载版**：即本文主要依据，阈限机场 + Class 5 + 登机逃生 + 模因污染，原作者 u/Liam0107，SetaCraft 重写。
  - **英文 Fandom 主站（backrooms.fandom.com）**：Level ∞ 为**空页**（未收录）。
  - **AMM 等衍生 wiki**：另有不同的 Level ∞ 设定。
  - 此外还需与「Level Absolute Infinity（绝对无限）」「Absolute Infinity of Unknown（未知的绝对无限）」「Level I N F I N I T E」等**不同条目**区分，它们都借用「无限」主题但属各自独立层级。
