# Level 3999（真结局 The True Ending / 霓虹乐园）及其子层级体系

> 别名：「The True Ending（真结局）」、「The Neon Paradise（霓虹乐园）」、「The Neon Arcade（霓虹街机）」。在体系中的特殊地位：它是后室中**极少数能让流浪者真正返回前室（Frontrooms / 现实世界）的「出口层级」之一**，并衍生出一整套子层级（sub-level）。

## 概述

**Level 3999** 是后室最负盛名的「终极/结局」层级之一，被广泛塑造为一座**霓虹灯复古街机厅（与影院）**。它的核心叙事是：这里是「真结局」——走对流程就能离开后室、回到现实。正因为这一「希望」属性，它催生了大量衍生子层级（3999.1、3999.9、3999...、3999-B、3999-C 等），共同构成后室中罕见的「编号家族（sub-level cluster）」。

它也是游戏《逃离后室（Escape the Backrooms）》Part 3 的**最终关卡**，承载游戏的「最终逃脱结局（Final Escape Ending）」。

## 描述与环境

### 原创 wiki 版（真结局 / 霓虹乐园）
- 一座看似无限的、被遗弃的现代街机厅，兼具复古影院性质。
- 大部分空间被霓虹灯和沿墙排布的街机（arcade machine）填满；主结构为：入口、废弃街机大厅、迷你街机厅。
- 被描述为「伪装成霓虹复古街机厅与影院的终端处理枢纽（terminal processing hub）」——一个「最终阈限序列（final threshold sequence）」。
- 投入任何硬币状物品（机器能接受任何能塞进去的货币或物体）即可玩游戏；流浪者沉浸于游戏时，**后室造成的长期负面精神效应会被缓解**，产生一种安心、正常的感觉。

### 《逃离后室》游戏版
- 一座空荡、废弃的现代街机厅，霓虹灯 + 街机沿墙。
- 结构：入口 → 长长的破败废弃街机大厅 → 末端的迷你街机厅（含一部需密码的电梯）。
- 迷你街机厅右上角有张桌子，上面的票券（Ticket）显示数字 **931**——即电梯密码。

## 实体

- **本层没有任何实体**，也没有异常物体（Object）——这是它作为「安全结局层级」的关键特征。

## 入口（Entrances）

- **原创版**：经由与「真结局」叙事相关的路径进入（多通过特定流程/谜题抵达）。
- **《逃离后室》游戏版**：
  - 利用 **Level 10（风车 / Windmills）** 中风车的指引光导航到那里的街机；
  - 从 The Hub（枢纽）中对应的门进入。

## 出口（Exits）

- **返回前室（核心）**：完成任务、走过玻璃门，会被送回前室（Frontrooms）——回到进入后室之前所在的地方。这是后室回归现实的极少数出口之一。
- **《逃离后室》游戏版的具体流程**：
  - 在电梯输入密码 **931**，观看（或跳过）天花板电视播放的 M.E.G. 文明科普视频（讲述穿墙 noclip 与 Level 0.2 红绿灯机制），电梯抵达 **Level 0.2**；
  - 进入废弃街机大厅的「员工专用门」前往 **The Hub**；
  - 从入口的旋转门返回 **Level 10**；
  - 集齐全部 4 个结局后，与房间顶部的大型 M.E.G. 街机互动可解锁主结局「最终逃脱结局（Final Escape Ending）」。

## 生存指南与可用物品

- 本层安全无实体，无需战斗或逃跑；核心是「解谜 / 走对流程」。
- **可用物品**：票券（Ticket，本层独有，显示密码 931）；街机可投入任意硬币状物体游玩，且游玩能缓解精神负面效应。
- **建议**：游戏版中不要跳过电梯里的科普视频（同一存档不会重播，含重要机制信息）；耐心找齐线索（电梯密码、各结局）。

## 子层级（Sub-Level）体系

Level 3999 是后室中少见拥有庞大子层级家族的层级，各 wiki 衍生出众多分支（彼此设定不统一，属社区扩展）：

| 子层级 | 常见设定 |
| --- | --- |
| **Level 3999...**（省略号） | 一座地铁站，分两部分（主厅 + 最后一站）；实体含 The Drivers（司机）与 Facelings（无面者）；逃脱需上大楼梯见强光，传送回前室。 |
| **Level 3999.1** | 早期存档 wiki 中的危险/黑暗变体。 |
| **Level 3999.9** | 另一数字子层级，设定各异。 |
| **Level 3999-B**（"The Dark Arcade" / "True Ending recovery"） | 「真结局」的黑暗/受损变体（The Dark Arcade，黑暗街机）。 |
| **Level 3999-C**（"The Ultimate Final Eternal Neon Paradise"） | 极致霓虹乐园的夸张版本。 |

> 这些子层级说明：后室的「小数/字母后缀子层级」往往是围绕一个著名母层级（如 3999、0.x）滋生的衍生创作群，权威性与一致性都低于主线整数层级。

## 轶事与版本差异

- **「四位数层级」**：在《逃离后室》游戏中，Level 3999 是唯一一个层级编号为四位数的关卡，也是 Part 3 时的最终关卡。
- **Buffalo 彩蛋**：开发者 Fancy 在第 8 期开发日志中曾说离开此层会到达现实中的纽约州布法罗（Buffalo, New York）；最终成品未完全照此实现，但该层被用于「最终逃脱结局」，玩家确实活着逃出了后室。
- **结局机制**：进入废弃街机大厅尽头的黑暗会触发过场——灯光亮起、走廊无限延伸，随后片尾字幕滚动。
- **版本差异**：
  - **原创各 wiki（Liminal Cannon / Redacted / Vertex / Freewriting 等）**：均以「霓虹街机 + 真结局 + 回前室」为核心，但 Liminal Cannon 等部分 wiki 已关闭，细节（影院、终端处理枢纽、子层级清单）各有出入。
  - **《逃离后室》游戏版**：Class 0、电梯密码 931、连接 Level 10 / Level 0.2 / The Hub、最终逃脱结局——更具体、可操作。
  - 主流后室 Fandom / Wikidot 主站对 Level 3999 的收录程度不一，它更多是游戏与衍生 wiki 共同塑造的「网络名层级」。
