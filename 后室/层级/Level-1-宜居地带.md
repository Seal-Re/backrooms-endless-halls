# Level 1（宜居地带，"Habitable Zone"）

> 别名：The Habitable Zone（宜居地带）。
> 后室第二个层级，是大多数流浪者真正开始"生存"的地方。

## 概述

Level 1 是从 Level 0 撞穿"闪烁的墙"后到达的层级，被描述为"地下停车场与废弃仓库无穷无尽的嵌合体"。相比 Level 0 的纯粹孤立，Level 1 拥有**可补给的资源、可建立的定居点、活跃的派系**，同时也住进了大量敌对实体。它是后室"社会"的起点，M.E.G.（Major Explorer Group，主要探索组织）等大派系的核心基地都设在这里。

> **版本说明（重要）**：本任务提示称 Level 1 为"电气化区"，但这与真实 wiki 设定不符。Wikidot 新版、Fandom 官方维基与中文 Wikidot 一致将 Level 1 命名为 **"宜居地带 / Habitable Zone"**（停车场+仓库形态）。Fandom 部分旧/分支版本也用过 "Parking Zone（停车区）"。本文以真实 wiki 为准。

## 描述与环境

- 宽阔开放的仓库式大厅，墙面褪色单调、绵延数英里。
- 周期排布的混凝土立柱、天花板上的管线、地面来源可疑的水洼。
- 空间呈**非欧几何**（non-Euclidean geometry）：感知到的距离并不可靠，导航必须依赖地标。
- 全层划分为六个区段（Sectors）：**天鹰段（Aquila）、跃金段（Gild）、哥特段（Gothic）、衔尾段（Ouroboros）、花园段（Garden）、传说段（Fabled）**。

### 关键环境特征

| 特征 | 说明 |
|---|---|
| **大厅（The Halls）** | 仓库式开阔空间，有周期性混凝土立柱，开阔但暴露。 |
| **走廊（The Corridors）** | 昏暗的迷宫式通道，比大厅更安全，无异常几何，但有无意义的房间（办公室、医务室、塞满怪异家具的橡胶房）。 |
| **闪烁（Flickering）** | 随机的全层停电事件，所有灯同时熄灭，敌对实体趁机出来捕猎。需沿墙、循绿色出口灯走向走廊入口避难。 |
| **板条箱（Crates）** | 随机出现（或闪烁事件后出现）的木箱，内含食物、水、工具、衣物、医疗用品。无人观察时会消失。 |

## 生存指南与可用物品

**即时优先级**：① 找到**杏仁水（Almond Water）**——主要饮品，同时补水并恢复认知；② 干净衣物与合脚鞋；③ 医疗用品（绷带、消毒剂）；④ 工具（撬棍、刀、打火机/火柴）。

- **导航**：用可见地标定位；在走廊用毛线作"阿里阿德涅之线"标记路径。
- **闪烁应对**：沿墙找走廊出口，**绝对不要奔跑**；非欧几何下奔跑可能反而把你带得更近实体。
- **扎营**：选卧室大小的走廊房间，用家具堵门（不要装永久锁，锁会消失），用箱板生火取暖。
- **避敌**：不要开枪（吸引更多实体）；闪烁时不要在大厅用光源；保持冷静、安静地撤回走廊。
- **C.L.I.P.P. 协议**（进入新层级时）：Check 环境威胁 / Locate 出口 / Inspect 数据库辨认层级 / Prepare 装备 / Perimeter 划定安全区。

### 主要定居点

- **M.E.G. Base Alpha（α 基地）**：天鹰段，全层最大定居点，招募并训练新人。
- **Trader's Keep（商人之家）**：跃金段，由 B.N.T.G.（后室非结盟贸易集团）经营，以物易物。
- **Hippocrates-1（希波克拉底团队）**：哥特段，阿里阿德涅圈（Ariane Circle）下属医疗基地，免费医疗。
- **Tom's Diner（Tom 的餐馆）**：全层社交中心，以物易物供餐。
- **Cornucopia（丰饶角）**：正义追寻者（Justice Seekers）总部，巡逻惩罚"罪人"。

## 轶事与版本差异

- **杏仁水**在本层具有异常营养特性，可同时补水与恢复心智清明，是后室最关键的资源。
- 本层据称已存在数个世纪，建筑风格随时代变化。
- 多个派系（M.E.G.、B.N.T.G.、阿里阿德涅圈、正义追寻者）在此竞争资源与控制权。新人常会同时遇到敌对实体与敌对人类。
- **版本差异**：
  - Wikidot / Fandom 官方维基 / 中文 Wikidot 均称 **"宜居地带 / Habitable Zone"**。
  - Fandom 经典版强调"巨大仓库 + 混凝土 + 暴露钢筋 + 无源低雾"，并称该层有稳定水电、可无限期居住。
  - 部分分支 Fandom 称之为 "Parking Zone"。
  - 任务提示的"电气化区"应为与 Level 3（发电站）的混淆，非真实设定。
