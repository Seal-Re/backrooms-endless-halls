# Level 28（阁楼 / The Attic · Final Virtue）

> 重大版本差异（两版完全无关）：
> - **Fandom 版**：Level 28「The Attic（阁楼）」又称「Crawlspace（爬行空间）」——无尽、黑暗、含剧毒隔热棉的阁楼空间，**Class 2**。本文以此为主线（与 Level 27「Ligneous Desolation」相连）。
> - **Wikidot 版**：Level 28「Final Virtue（最后的美德）」——永久阴天的草原与中央城堡，**Class 2**。详见末尾版本差异。
>
> 注意：Fandom 的 Level 28「The Attic」与后室中另一独立地点「The Attic（阁楼）」不是同一个，勿混淆。

---

## 概述

Level 28（Fandom 版「The Attic / Crawlspace」）是后室第 29 个层级，似与 Level 27 相连——通过梯子连接。它表现为一系列积尘、破旧、不一致的老旧阁楼空间，堆满纸箱与破家具，照明昏暗难寻。最大危害是地面厚厚的**剧毒粉色隔热棉**与同样有毒的空气。

Fandom 版威胁等级 **Class 2**，细分评分：

- **Exit（出口难度）：1/5**——容易离开（Easy to Exit）
- **Environment（环境风险）：3/5**——高环境风险（High Environmental Risk）
- **Entities（实体）：3/5**——重大敌对存在（Major Hostile Presence）

---

## 描述与环境

- **无自然光**：层级内**完全没有自然光**，仅有来源不明、极微弱的辉光。强烈建议自带照明，否则几乎无法深入。层级还有异常效应**抑制人眼对黑暗的适应**，使人陷于全黑。
- **天窗与通风口**：天花板偶现小窗与通风口，但所有外部光源都被层级黑暗吸收，窗外只见深蓝色调；通风口不提供任何空气循环。墙侧偶见连接屋顶与地面、有时沿墙延伸的通风管。
- **粉色隔热棉（主要危害）**：地面铺有约 1–3 英尺厚的粉色隔热棉，表面覆尘显白。其成分不同于普通隔热棉（玻璃纤维/岩棉/纤维素），而含**砷、钋、铍等有害金属**；还混有数万根可刺穿皮肤与多数织物的微观针，针中据信含微量 **Liquid Pain（液态痛苦）**，接触会剧痛或更糟。**务必穿合适鞋具**（多数运动鞋/皮鞋可抵御），行走时应保持直立，除非穿着 M.E.G. 认可的防护服。曾有争论隔热棉是否为独立实体，但多数将其归类为高危「物品」。
- **有毒空气**：空气同样剧毒，虽不致快速死亡，但无专业装备吸入会致头晕、气短、头痛，久留可窒息。M.E.G. 专家推测含高浓度氮气（N₂）与二氧化碳（CO₂）。
- **结构脆弱**：木结构因老化而不牢，承重过大时木板会在特定处坍塌、坠入下方空腔（深度不致命但可致伤）；部分阁楼房间地板已碎裂，形成深洞（成因不明，不会修复）。
- **物资与异象**：角落偶有箱子（纸箱含关键食品、电器、编目物资）；墙上有蛛网（但无活物迹象）；杏仁水（Almond Water）会无中生有地从天花板渗滴、形成水洼；部分人称隐约听到雨声（多为异常假声）。**发光板（Glowing boards）会致癫痫或电击，切勿触碰**。

## 实体

**Fandom 版：**
- **Attic Dwellers（阁楼居民）**：威胁等级 5；细长高瘦的黑色「火柴人」形象，白眼，潜伏徘徊；智力高（4/5，人类级），能很快锁定目标；身高从不超过约 4 英尺（约 0.9–1.2 米），因身材矮难穿过结构（可助逃脱）；无性别、不能繁殖（因此正快速濒危消失）；可用枪射杀；皮肤多皱、黏腻油亮，脑小、不能发声，足适于狂奔与在窄处爬行，体内几乎无器官（仅心、脑、眼）；会先静立、再把人「吸入」体内。攻击多致命（5/5）。栖息地为 Level 28 与 Level 799。
- 下层（更开阔）区域有 **Death Moths（死亡蛾）**，故不太建议走下行楼梯；另有 **Smilers（微笑者）、Foams（泡沫）、Wretches（可怜虫）** 的确认报告；层侧据称发现过 **Skin-Stealers（夺皮者）与 Hounds（猎犬）的尸体**（未证实）。

**Wikidot 版：**
- 几乎完全无实体（常见敌对生物一进入就崩解）；唯一住民是 **Blue Knight（蓝骑士，称"Temperance/节制"）**——一副空心铠甲，非敌对、会帮助流浪者，但可能不愿透露出口信息。

## 入口（Entrances）

**Fandom 版：**
- 在 **Level 1** 相对矮小的墙上找到「Holes（洞）」，爬过去即到，入口随后消失（传闻 Level 4、Level 8 也可能出现，未证实）；
- **Level 27** 天花板偶现的活板门（trapdoor），爬上来到此；
- **Level 80** 中一个带钟的木箱「可能」送来此处。
- 此外，Level 28 本质上是 Level 27 的阁楼，通过梯子相连（Level 27 约有 5 架梯子；从梯子进入可能晕倒坠落、醒来即在 Level 28；地板里见到木梁说明离入口更近，背景音乐会随接近而变响）。

**Wikidot 版：**
- Level 5 上酷似该层的画作；
- 在森林层级（Level 14、199）跟随粉色蝴蝶；
- Level 82 的某些便利店；
- 从 Level 104「Fortress（堡垒）」的屋顶跳下。

## 出口（Exits）

**Fandom 版：**
- 箱中可能有老旧朽坏的游戏机（consoles），激活即 noclip 到 **Level 25**（同类机器在其他层无效）；
- noclip 穿过一堆废弃票券 → **Level 154**；
- 较高天花板区域的轻微受损木门 → 随机通向 **Level 483、5、12、19、20、42** 之一；
- 死胡同处的窗户，破窗 noclip → **Level 9、38、597 或 39**；
- 成功破开屋顶 → 强制 noclip 进 **Level 398**；
- 某些区域 → **Level 0.7**；更大区域 → **Level 27.3**；
- 爬下梯子 → **Level 27**；
- 在 Level 28 找到一个带门的荒废木箱：房间像派对 → **Level 90**；房间空无一物 → **Level 10**。
- 备注：Level 0 与 Level 28 是仅有的两个确认通往 Level 483 的层级。

**Wikidot 版：**
- Abyss（深渊）水池 → Level 10.1、41 或 88；
- Keep（城堡）内的灯 → Level 4 或 5；
- 闪电击中处 → Level 73；
- 铁匠铺熔炉 → Level 611；
- 森林通道 → Level 9.3；
- 城堡上锁的门 → Level 381。

## 生存指南与可用物品

**Fandom 版：**
- **必带照明**（层级抑制暗适应，无外部光源几乎无法行进）。
- **穿合适鞋具、保持直立**：粉色隔热棉含砷/钋/铍 + 含液态痛苦的微针，绝不可赤足或匍匐于上（除非有 M.E.G. 认可防护服）。
- **防有毒空气**：尽量配备专业呼吸装备，避免久留导致窒息。
- **绝不碰发光板**（致癫痫/电击）；小心脆弱木板坍塌坠洞。
- 物资：纸箱含食品/电器；天花板渗滴杏仁水可补水。

**Wikidot 版：**
- 远离 **The Living Abyss（活体深渊）**：一种有意识的焦油状物质，接触后经三阶段（失忆→身体衰败→崩解）约 11+ 小时致命；它会主动避开**周期性闪电**区域，可借此自保。
- 可向非敌对的 Blue Knight 求助。

## 轶事与版本差异

### Fandom 版轶事
- 页面以第二人称叙事开场：「你醒来……身体酸痛……你在探索 Level 27 时睡着了……你看见头顶悬着一架梯子」——爬上梯子进入 Level 28；从 Level 27 经梯子进入后回头看梯子，有 50% 概率消失，若不消失则被送往 Level 14。
- 隔热棉地板下还有额外的空爬行空间，其用途与阁楼的连接关系未明。

### 版本差异：Wikidot 版 Level 28「Final Virtue（最后的美德）」
- 永久阴天、被微弱蓝光（非日月）照亮的草原王国，中央有神秘城堡 **Stormstone Keep（风暴石要塞）**，四周被「The Living Abyss（活体深渊）」从群山逼近。
- 安全区约 13.5 公里（8.4 英里）宽；虽阴云密布却从不下雨。
- **危险等级 Class 2（Mostly Safe，基本安全）**，实体极少，结构相当稳固。
- **Stormstone Circle（风暴石环）**：六块环形立石，各刻有符文与美德之名（Prudence 审慎、Hope 希望、Faith 信仰、Fortitude 坚毅、Justice 正义、Charity 仁爱）；受损石头会自我重建。
- **周期性闪电**：每小时在七个轮换区域落雷；深渊主动避开；此处存在时间膨胀——外部设备记录落雷间隔约 51 分钟。
- 回收日志揭示悲剧叙事：六位以美德命名者牺牲自己保护此层，仅剩蓝骑士 Temperance（节制）继续对抗深渊推进。

### 版本对照小结
- 名称：Fandom =「The Attic / Crawlspace（阁楼）」；Wikidot =「Final Virtue（最后的美德）」。
- 等级：两版都标 Class 2，但内涵迥异——Fandom 是高环境/实体危害的毒阁楼；Wikidot 是基本安全的美德城堡草原。
- 二者**毫无共同点**。
