# Level 16（地形变换 / Altered Topography）

## 概述

Level 16 现行 Wikidot 版名为 **「Altered Topography（地形变换 / 改变的地貌）」**，是一个会**不可预测地切换自身地貌形态**的自然层级。它最显著的特征是存在两种（或更多）截然不同的「状态档案（File）」——目前记录的两种为**雨林状态**与**北极状态**，层级会在未知时间间隔内在这些状态之间不可预测地转换地形。

---

## 描述与环境

本层以「档案（File）」形式记录其不同形态：

### File 1 — 雨林状态（Rainforest Configuration）
- 一片热带雨林生态系统，常年弥漫浓雾。
- **重力异常**：重力显著降低，但**只影响外来物体/实体**（即雨林本身的植物正常，外来者会变轻）。
- 温度恒定在 **21°C / 70°F**。
- 光照恒为黎明状态（perpetual dawn），**没有昼夜循环**。

### File 2 — 北极状态（Arctic Configuration）
- 北极气候，遍布发光、反光的冰面。
- 拥有约 **13 小时的昼夜循环**。
- 温度范围 **6–10°C**。
- 地貌会在未知间隔内**不可预测地发生地形变换**。

---

## 生存难度（Survival Difficulty）

| 项目 | File 1（雨林） | File 2（北极） |
|---|---|---|
| 危险等级（Class） | **0**（具体分项不明） | 不明（Unknown） |
| 环境风险 | 中（重力异常、浓雾） | 中（严寒、地形突变） |
| 实体数量 | 低 | 含大量 Light Guides（异常聚集） |
| 稳定性 | **低**——地貌会不可预测变换 | 低——地形不可预测转换 |
| 出口数 | 通向 Level 46 | 通向 Level 46 |

总体定位：**名义上 Class 0，但因地貌会不可预测地整体切换，长期居住不可行；主要危害是地形转换时被困/受困（terrain entrapment）。**

---

## 实体

- **北极状态（File 2）** 中观测到了**大量聚集的 Light Guides（光之向导 / Entity 35）**。这一点非常反常——因为 Light Guides 本身相当罕见，且**从不成群出现**，唯独在本层的北极状态会大规模聚集，原因不明。
- 雨林状态未记录显著敌对实体。

---

## 入口（Entrances）

- **File 1（雨林）**：触摸 **Level 75** 中类似铜的液态金属（copper-like liquid metal）。
- **File 2（北极）**：触摸 **Level 75** 中的橙色镓（gallium）斑块。

> 两种状态的入口都来自 Level 75，但触碰的「液态金属」种类不同，决定进入哪种地貌状态。

---

## 出口（Exits）

- **两种状态通用**：找到一片被沙覆盖的表面——
  - 雨林状态下是一棵被沙覆盖的树；
  - 北极状态下是一块被沙覆盖的冰面——
  由此可前往 **Level 46**。

---

## 生存指南与可用物品

- **地形会突变，做好被困准备**：本层最大的危害是**地貌在未知时刻不可预测地整体转换**，转换过程中存在被地形困住（terrain entrapment）的风险。不要在低洼、封闭或易被掩埋的地形久留。
- **不宜长期居住**：由于环境不稳定（地貌随时切换、温度/重力剧变），本层不适合永久定居。
- **应对重力异常（雨林）**：在雨林状态下，外来者会变轻，移动与跳跃要格外小心，避免失控。
- **应对严寒（北极）**：北极状态温度 6–10°C 且冰面反光刺眼，需做好保暖与防眩。
- **避开光之向导群（北极）**：北极状态下反常聚集的大量 Light Guides 行为不明，建议保持距离观察。
- **尽快定位沙覆盖表面**：无论处于哪种状态，找到被沙覆盖的树/冰面即可离开前往 Level 46，这是相对可靠的脱离手段。

## 轶事与版本差异

- **「多状态层级」设计**：Level 16 用「File 1 / File 2」的档案结构来表达「同一层级、多种地貌」，这种写法是后室创作中表现「不稳定/变形层级」的常见手法，也暗示可能还存在未被记录的其它状态。
- **Light Guides 的反常聚集**：通常罕见且独行的光之向导在此成群，是本层最大的谜团之一，常被社区讨论。
- **与 Level 75 的强绑定**：本层的两个入口都源自 Level 75 的不同液态金属，使 Level 75 成为进入 Level 16 的关键门户。
- **中文译名**：中文社区译作「地形变换」「改变的地貌」或「地形转变」。
