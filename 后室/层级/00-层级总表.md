# 后室层级总表（全量索引）

> 本文件是后室（The Backrooms）层级的**全量索引**，目标是覆盖尽可能多的层级编号——从 Level 0 一直到 Level 999，外加著名的负层级、子层级、隐秘/特殊层级与高编号"梗"层级。
>
> **数据来源以 Wikidot 新版维基为主**（The Backrooms Wiki / The Backrooms 中文维基），辅以 Fandom 旧版与中文社区资料。后室是社区集体创作，存在 **Fandom 旧版 / Wikidot 新版 / 中文版** 三套常相互冲突的设定，本表在条目内用「版本差异」标注主要分歧。
>
> 译名说明：层级名首次出现给中文译名，并保留原英文名/原编号。中文名优先采用 Wikidot 中文维基的官方译名；若该编号在中文维基暂无译名，给出直译并标注。

## 0. 阅读说明与重要版本差异

### 0.1 三套维基的关系（必读）

| 平台 | 站点 | 特点 |
|---|---|---|
| **Wikidot（新版/正典向）** | `backrooms-wiki.wikidot.com`（英）、`backrooms-wiki-cn.wikidot.com`（中） | 有审核+评分机制（类似 SCP），质量高、设定较新。**很多经典层级被重写、改名甚至删除**。本表的层级名以此为基准。 |
| **Fandom（旧版/原生梗向）** | `backrooms.fandom.com` 等 | 最早承载"黄房间""逃命""派对客"等经典设定的地方，数量多但质量参差。许多人记忆中的后室来自这里。 |
| **中文社区** | 萌娘百科、百度百科、MC百科、知乎、风室 `backroom-cn.wikidot.com` 等 | 主要做翻译与二次整理。 |

### 0.2 最关键的几处版本差异

- **Level 0**：Wikidot 新版名为 **"Threshold（阈限）"**；Fandom 旧版及大众认知中是 **"The Lobby（大堂 / 黄房间）"**——即那张著名的发黄办公室隔间照片。两者描述高度相似（单调黄墙纸、潮湿地毯、嗡嗡作响的荧光灯、非欧几何空间），仅名称体系不同。
- **派对客 / Level Fun**：Fandom 经典的"享乐层 Level Fun + 实体派对客 Party Goers"在 Wikidot 被**重构**——派对客在英文 Wikidot 改写为 **Entity 67**，中文 Wikidot 为 **Entity C-233**，相关层级被改名/拆分。Fandom 后来把"派对客"设定改成 **Crimson Revelry（绯红狂欢）**。
- **Level !（逃命 / Run for your life）**：Fandom 旧版著名的"最危险层级"（约 10 km 长的医院式走廊，实体高速追猎）。Wikidot 体系基本未保留同名条目，相关恐惧被分散到其他隐秘层级。
- **大量编号层级在 Wikidot 处于"重写中（under rewrite）"或"[无数据/待撰写]"状态**——本表保留这些占位编号以体现"全量索引"，标注为 *[占位/无数据]*。
- 同一编号的层级名，**中英 Wikidot 偶有不同步**（例：Level 2 英文 "Abandoned Utility Halls" vs 中文较早译作"废弃公共区域"；Level 11 英文 "The City That Never Sleeps" vs 中文"永恒之城"）。表中以英文名为锚，中文名取中文维基译名或直译。

### 0.3 生存难度（Survival Difficulty Class）体系

Wikidot 维基用 **Class 0–5** 标记层级危险度（信息不足则为 *未定 Undetermined*）。本表"生存难度"列尽量给出该值，未明确的留空或标"未定"。

| Class | 含义 | 通俗说法 |
|---|---|---|
| **Class 0** | 完全安全、稳定、无实体、无环境危害 | 可长期居住 |
| **Class 1** | 基本安全，少量威胁（少量实体/略难导航） | 大体安全 |
| **Class 2** | 不安全、稳定、低实体数 | 需警惕 |
| **Class 3** | 不安全、不稳定、中等实体数 | 危险 |
| **Class 4** | 高实体数、严重威胁，应避免 | 高危 |
| **Class 5** | 极端威胁，不惜一切代价避免 | 死地 |

> 注：早期 Fandom 用 "Survival Difficulty / Class 1~5 + Safe/Unsafe/Entity Count" 三段式描述，与上表大同小异。

## 4. 负层级（Negative Levels）

> 负层级位于 Level 0 之下，编号前带负号。与正层级以"空间阈限"为主不同，负层级偏向 **REM 睡眠般的超现实、致幻、心理性阈限**，普遍极度危险。

> **版本差异（重要）**：Fandom 旧版曾系统化设有"负层级"体系；后来 Fandom 社区曾讨论/部分**移除负层级**，而 Wikidot 体系则把这类内容多数并入"隐秘层级"。因此不同维基的负层级清单出入很大。
