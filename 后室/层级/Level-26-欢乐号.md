# Level 26（欢乐号 / The SS Fun =) · Otherworldly）

> 重大版本差异（两版完全无关）：
> - **Wikidot 版**：Level 26「The SS Fun =)（欢乐号）」——一艘 noclip 进入后室的现实游轮，**Class 5（实体感染）**。
> - **Fandom 版**：Level 26「Otherworldly（异界）」又称「Suburban Household（郊区住宅）」——无尽的 1980 年代迷宫式住宅，**Class 4**。
>
> 本文同时详写两版（互不相同），并在末尾给出对照。

---

## 概述

**Wikidot 版「The SS Fun =)（欢乐号）」**：由一艘从现实（Frontrooms）noclip 进入后室的游轮《Adventure（冒险号）》构成，船长约 500 英尺、宽约 60 英尺，原名被涂鸦刻意改成「SS Fun =)」。它是一个移动的、永不在同一地点出现的「派对王国」。M.E.G. 评论道：「后室要如何打败一个永远不在同一地点的旅行王国？」威胁等级 **Class 5 - Unsafe, Unsecure, Entity Infestation（不安全、不安保、实体感染）**。

**Fandom 版「Otherworldly（异界）/ Suburban Household（郊区住宅）」**：后室第 27 个层级，呈现为迷宫式的 1980 年代城市住宅，可能延伸数百万公里（真实尺寸未知，因布局混乱、非线性）。威胁等级 **Class 4**：不安全（Unsafe）、不稳定（Unstable）、高实体数量（High Entity Count）。

---

## 描述与环境

### Wikidot 版（欢乐号）
- **外部**：上层甲板像一场「永恒的恶魔兄弟会派对」——大肆破坏、血溅、舱室被毁；一个深红色泳池中泡着活人与死者；残留餐厅、酒吧、休息室。
- **内部**：下层甲板**无限大**，「尖叫声在无尽走廊里回荡」。派对房间按电影、节日等主题布置，装饰物被设了陷阱。电梯系统作为枢纽向各方向分叉。整个内部是「恐怖的大杂烩」。
- **关键现象**：船会周期性地在「绿雾」中消失；无需发电机，电力却持续供给所有电路；内部空间**无限大于**外部。
- **Phenomenon 7 - Liminal Echo（阈限回响）**：船内一股有意识的力量，能独立生成、复制区域，与 Partygoer（派对客）的想象力形成协同关系。

### Fandom 版（异界 / 郊区住宅）
- 迷宫式 1980 年代住宅，结构与 Level 0 相似：混凝土墙覆单黄色调壁纸；地毯几近完好却积尘，多为米/绿/灰色带图案；石膏混凝土天花板呈象牙色；荧光灯具照明，但仍有暗区（实体可能出没）。
- 暗区偶有损坏与抓痕（疑为 Hounds 所留，未证实）。
- 走廊狭窄压抑（宽约 0.5–2 米），有的需弯腰或侧身通过，有的完全无法通行，常被家具堵塞。
- 结构荒诞、非欧几里得（non-Euclidean）：走廊通向死胡同、门开向墙、房间以不可能的方式重叠交叉；房屋像被「拼接」而成。
- 房间像普通住宅（卧室、客厅、厨房、餐厅等），但**没有任何卫生间的报告**。
- 含「物理上不可能的连接」家具（无腿悬空的椅、立在墙上的桌、画布与颜料分离数英尺的画）——**与这些"glitch"物品互动会立即 noclip 进任意一个负数层级（Negative Levels）**。书架上的书名荒诞（如《A Delicious Hallway》《Do Not Not Not... Read Me》《I'm Not a Book, I'm An Entity》等），部分书页全透明空白。
- 子区域含 The Empty Rooms（空房间，仅地毯与单黄壁纸，实体常潜伏其中）等。

## 实体

### Wikidot 版（欢乐号）
- **Partygoers（派对客，Entity 67）**：占主导的物种，组成有组织的社会；本层是其文明的总部。
- **Carnivorous Balloons（食肉气球，Entity 110）**：栖于黑暗角落的利齿实体，与派对客争夺人类食物来源。
- **Entity 167**：被描述为「一个长着眼睛-嘴巴组合的金色煎蛋」。
- **Facelings（无面者，Entity 9）**：船上有此实体，被记录到被喂给其他生物。

### Fandom 版（异界）
- 实体众多，**Windows（窗，伪装成窗的实体）最普遍**；
- 另有 **Hounds（猎犬）、Smilers（微笑者）、Skin-Stealers（夺皮者）**；
- 暗处可探测到 **Wretches（可怜虫）**，但似乎对流浪者无敌意。

## 入口（Entrances）

### Wikidot 版（欢乐号）
- 在后室任何地方触碰派对相关物（气球、派对帽、装饰、海报）；
- 在船现身后登船。

### Fandom 版（异界）
- 没有稳定入口；可能从 **Level 5、Level 21、Level 25、The Hub、The Attic** 随机来此。

---

## 出口（Exits）

### Wikidot 版（欢乐号）
- 触碰一张反向、失焦的派对海报（传送到另一层级）；
- 跳船（jumping overboard）。

### Fandom 版（异界）
- 某些楼梯 → The Attic（阁楼）、Level 26.1 或 Level 27；
- 某些（常错位的）木门 → Level 42；
- 若窗外突然变深红，从任意窗户离开 → Level 93；
- 某些走廊 → Level 193；
- 带着本层物品、从任意先前出口离开 → Level 955。

## 生存指南与可用物品

### Wikidot 版（欢乐号）
- **唯一记录在案的逃生幸存者**是 April Showers：在其姐姐变成派对客生物后，她触碰太阳甲板上一张反向海报逃出。
- 切勿触碰被设陷阱的派对装饰；警惕黑暗角落的食肉气球争食。
- 出口稀缺——记住「反向失焦海报」与「跳船」两条路。

### Fandom 版（异界）
- **绝不触碰"glitch"家具**（会 noclip 进负数层级）。
- 避开暗区（实体出没、有抓痕、通风口异常寒冷）。
- 狭窄走廊需弯腰/侧身，注意被家具堵塞的通道与通向墙的假门。
- 房间内可找到 1980 年代家具/物品（部分悬空异常），无卫生间；曾有殖民地遗迹（腐尸、锈机、坏家具）说明此处曾有人居。

## 轶事与版本差异

### Wikidot 版轶事（欢乐号）
- **船体来历**：据称船钢来自 USS *Eldridge*（DE-173）——1943 年「费城实验（Philadelphia Experiment）」中试图用谐波力场实现隐形的那艘船；该舰后移交希腊改名 *Leon*（D-54），1999 年拆解。
- **领袖**：Deacon Duncan，被认定为「Partygoer Zero（派对客零号）」，自封天才，通过匿名情报向 M.E.G. 提供信息。
- 《Adventure（冒险号）》已记录在至少 13 个已知层级现身，包括 Level 134、180、230、10、121、184、246。

### Fandom 版轶事（异界）
- 物理空间非欧几里得：朝一个方向走可能不会通向该方向，甚至在未转弯的情况下绕回原点（与 Level 0 类似）。
- 土壤缺乏细菌、氮含量为北美草原平均水平——在无阳光、天气怪异恒定的条件下植物如何繁茂、是否存在氮循环，成谜。

### 版本对照小结
- 名称：Wikidot =「The SS Fun =)（欢乐号，游轮）」；Fandom =「Otherworldly / Suburban Household（异界 / 郊区住宅）」。
- 等级：Wikidot Class 5（实体感染移动王国）；Fandom Class 4（非欧住宅迷宫）。
- 二者**毫无共同点**，属典型「同号不同设定」。
