# Level 8（岩洞系统，"Cave System" / "Cave Systems"）

> 别名：Cave System / Cave Systems（岩洞系统）。中文 Wikidot 译名"岩洞系统"。

## 概述

Level 8 是一片无限延伸的地下洞穴系统，几何非欧、重力紊乱、熵加速、空气有毒，每个拐角都潜伏着掠食者。它在任务提示中被混称为"地下停车场"，但真实 wiki 名为 **"Cave System / 岩洞系统"**（地下停车场意象属 Level 1 的一部分）。这里以巨型蛇形掠食者"牧蛇"和成群的蛛形生物闻名，是后室中环境最严酷的层级之一。

## 描述与环境

无限的地下洞穴系统，具复杂的**非欧几何**，"黑暗、压抑、危险，掠食者环伺"。

### 关键环境危害

| 危害 | 说明 |
|---|---|
| **不稳定物理** | 非线性空间，路径会自我循环回到原点。 |
| **波动重力** | 不同洞窟间重力的强度与方向不可预测。 |
| **加速熵** | 食物迅速腐败、电池快速耗尽、人类加速衰老。 |
| **危险大气** | 缺氧、二氧化碳积聚、有毒气体（硫化氢、氯气、氨气）。 |
| **水患** | 杏仁水池、突发洪水、溺水风险。 |
| **极端温度** | 视位置在 50–60°F 到 110°F+ 之间波动。 |

### 重要地点

- **多维之路（Multidimensional Road）**：发光细菌生态系统，栖息着萤虫（Glowworms）。
- **罗特尼斯特林（Rottnest Grove）**：重力独特的巨型洞窟，生物荧光真菌密布。
- **新莫维尔洞（New Movile Cave）**：化能合成生态系统，毒气弥漫。
- **巨臂林（Giant Arm Grove）**：最大的单一洞窟，布满手掌形钟乳石。
- **蜂巢（The Hive）**：禁区——建议"只能祈祷"。

## 生存难度（Survival Difficulty）

| 项目 | 评定 |
|---|---|
| **危险等级（Class）** | Class 4（逃脱难度 4/5，环境危害 4/5，实体威胁 4/5） |
| **实体数量** | 高（多种高度敌对实体） |
| **稳定性** | 低（非欧、重力波动、熵加速，极不稳定） |
| **出口数** | 多个（推荐"第九大道"路线） |

## 实体

- **牧蛇（Shepherds）**：巨型蛇形掠食者，长可达数英里。
- **蛛形生物（Arachnids）**：多种蜘蛛，含具领地攻击性的变种。
- **焦油之手（Pitch Hands）**：焦油状物质池，伸出抓握的肢体。
- **悲尸（Wretches）**：僵尸状被感染实体。
- 其他：死亡飞蛾、伪装爬菌、萤虫等。

## 入口（Entrances）

- 主要来自 **Level 6**（多条路线经此进入）与 **Level 7**（午夜带底部岩洞）。
- 多个层级的地面塌陷、隧道连接等。

## 出口（Exits）

- **推荐："第九大道"（The Ninth Avenue）** → **Level 9**：M.E.G. 维护的路线，从 Level 6 入口连到 Level 9，沿途有物理较稳定的"岛屿"，每约 50 米设标志，途经多个 M.E.G. 与盟友社群。
- 罗特尼斯特林的通风井 → Level 2。
- 焦油坑坠落 → Level 41 或 91。
- 银色物质隧道 → Level 75。
- 穿墙 → Level 93。
- 地面坠落 → Level 69。

## 生存指南与可用物品

- **结伴、沿"第九大道"标志前进**——独闯非欧洞穴极易迷失或被掠食者捕杀。
- **携带呼吸防护**：随时可能遭遇硫化氢/氯气/氨气等致命气体。
- 因**熵加速**，食物会很快腐败、电池很快没电——补给要勤换、电筒要备份。
- 避开**蜂巢（The Hive）**与焦油之手池。
- 注意波动重力，过桥/攀爬前先试探重力方向。

### 殖民地 / 派系

- **M.E.G. "空巢"哨站（Empty Nest）**：主要安全港。
- **哈茅斯洞穴学会（Harmouth Speleological Society）**：100+ 名经验丰富的探险者。
- **失落部族（Lost Tribes）**：独立的狩猎队。
- **挚爱唱诗班（The Beloved Choir）**：位于罗特尼斯特林的宗教社群。

## 轶事与版本差异

- "第九大道"是后室著名的"安全走廊"工程范例——M.E.G. 在极端不稳定的层级中硬生生维护出一条带路标的可通行路线。
- **版本差异**：
  - Wikidot 英文标题为 **"Cave Systems"**（复数），Fandom/中文 Wikidot 多作 **"Cave System / 岩洞系统"**。
  - 各版核心一致：无限非欧洞穴、牧蛇与蛛形生物、毒气、熵加速、通往 Level 9 的"第九大道"。
  - 任务提示"地下停车场"非本层设定（停车场意象属 Level 1）。
