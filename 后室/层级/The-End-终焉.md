# The End（终焉 / 终点 / Level 601）

> 「The End」在不同 wiki 体系中对应两套差异极大的设定，但都以「无尽的图书馆」为核心意象，且都暗示自己是后室的某种「终点 / 阈限 / 终极陷阱」。本文同时收录两版并标注版本差异。

## 概述

**The End（终焉）** 是后室中极具哲学与元叙事色彩的层级之一，名字本身就宣称这是「终点」。它的两个主要版本分别强调不同主题：

- **英文 Fandom 版「The End」**：一座近乎无限的、衰败的**空图书馆**，被定性为「层级与层级之间的空间阈限（in-between space）」——一个空洞的、意义被抽空的中间地带。Class Beta。
- **Wikidot 版 / 中文维基「Level 601『终点』」**：一座无尽的现代图书馆，是一个**陷阱层级（Trap Level）**，制造「已逃离后室」的假象，用「假现实（Fake Realities）」让流浪者陷入唯我论妄想，受神秘实体「笑面」操控。

两版都不是用来定居或穿越的常规层级，而是承载「后室是否有尽头 / 出口 / 意义」这一母题的概念性空间。

## 描述与环境

### 英文 Fandom 版「The End」
- 一座**推定无限的图书馆**，由开阔区域和宽走廊组成；有书架、阅览台等常规图书馆陈设，但**几乎没有书**，书架空荡。
- 家具常随机摆放，有时相互交叠或嵌入墙壁；墙上散布无意义的短文和标签，常写着本层的名字「The End」。
- 状态破败，呈现时间性衰朽：墙有裂缝，部分书架轻压即塌；灯光故障，时而闪烁或短暂熄灭。
- 散布**老式电脑**（酷似复古个人电脑）：外观崭新且不可摧毁，但几乎都不能用或没插电；少数能开机的也只亮几秒、随即化为渐隐的雪花噪点，开机时发出轻微嗡鸣并以白字显示本层名字，之后再也无法开启。
- 声音被严重压制，最安静时接近 **0 分贝**；附近电脑和微弱荧光灯会打破寂静。
- 几何**松散定义**，会扭曲变形，导致一切导航手段失效；长期暴露常引发听觉和视觉幻觉。
- **本质**：只是一个空壳，其无意义的存在仅仅是一个**空间阈限——层级之间的中间地带**。

### Wikidot 版 / 中文「Level 601『终点』」
- 一座看似无限的**现代图书馆**，中央区域用金属字母拼出「**the end is near（终点将近）**」。
- 极度寂静，某些区域低至 **-6.2 dB**；几何结构不稳定，走廊不断循环。
- 中央有持续嗡鸣的电脑终端（在寂静中显得格外突兀）。
- 关键异常：「**假现实（Fake Realities）**」——熟悉的环境，里面发生着正常的人类互动，引诱流浪者沉溺。
- 技术失灵：所有无线、Wi-Fi、电子设备都失效，唯独本层原生终端能用。

## 实体

- **英文 Fandom 版**：定性「毫无生命（Devoid of All Life）」——没有常规实体；威胁来自隔绝、扭曲与幻觉本身。
- **Wikidot / 中文 Level 601**：
  - **派对客（Partygoers / 派对客）**：频繁出没于电脑终端区域，据报会绑架流浪者。
  - **笑面（The Smile / 笑面）**：神秘的「控制」实体，指挥其他生物。

## 入口（Entrances）

- **英文 Fandom 版**：入口极罕见，缺乏可靠记录；常以**不可摧毁的、没有门扇的木质门框**形式出现，门框另一侧的景象通常是扭曲的、附近声波明显减弱。穿过门框后入口立即消失，将流浪者留在 The End 的无限之中。
- **Wikidot / 中文 Level 601**：标有霓虹「exit」字样的门（最常见）；罕见的随机穿墙（no-clip）进入（不可预测）。

## 出口（Exits）

- **英文 Fandom 版**：
  - 在「扭曲（Distortion）」发生时穿墙（noclip），会引发能量波动，使流浪者进入该次扭曲所呈现的场景（如雪原、Lobby 大堂等）。
  - 或找到一扇通向随机层级的出口门。
- **Wikidot / 中文 Level 601**：假现实中有时含有通往较安全层级的通道；但**无可靠的逃脱方法**，可能经由假现实过渡到后室其他层级。

## 生存指南与可用物品

- **不要沉溺于「假现实 / 扭曲场景」**（Wikidot 版尤甚）：那些熟悉、温馨、正常的场景是陷阱，会诱发唯我论妄想，让人忘记自己仍被困。
- **警惕幻觉**：长期停留会产生听觉和视觉幻觉，需保持对真实环境的判断。
- **利用扭曲逃生**（Fandom 版）：扭曲发生时是少数能离开的窗口，可在此时穿墙。
- **不要指望电脑**：电脑多不可用，能用的也只显示层名后即永久失效。
- **基地/社区**：Wikidot 版记载有一个名为「**瘾客（The Junkies）**」的 6 人团体栖居于假现实中，依赖「记忆果汁（Memory Juice）」，B.N.T.G. 曾尝试营救但未成功。

## 轶事与版本差异

- **同名异设（核心版本差异）**：「The End」在英文 Fandom 是独立的概念性阈限图书馆（Class Beta）；在 Wikidot/中文体系里则编号为 **Level 601「终点」**，是一个带派对客与「笑面」的心理陷阱层级。两者都用「无尽图书馆」意象，但机制和威胁来源完全不同——这是后室「多 wiki 版本设定冲突」的典型案例。
- **元叙事色彩**：两版都暗示 The End 与「整个后室」存在某种深层联系（Fandom 版借扭曲场景里出现 Lobby 等已知层级提出此疑问；中文 Level 601 的结尾独白暗示有实体在无限虚空中散播「虚假的满足」）。
- **「the end is near」**：Wikidot 版中央的金属字标语是本层最具辨识度的视觉符号，强化了「终点 / 末日将近」的宗教与末世意味。
- 还需区别：另有名为「**Level ∞**」「**The Final Outpost**」等同样带「终点 / 终极」意味的层级，与 The End 是不同条目，不应混淆。
