# 后室与 SCP 基金会的关系：渊源、区别与空间异常类 SCP 关联

> 后室（The Backrooms）与 SCP 基金会（SCP Foundation）常被相提并论，许多人误以为「后室是 SCP 的一部分」或「后室出自 SCP 基金会」。**这是误解。** 二者今天是**完全独立的两个虚构宇宙**，仅有**历史渊源与风格借鉴**，并无官方设定上的从属或交叉。本篇说清楚三件事：(1) 二者的真实关系；(2) 后室如何借鉴 SCP 的协作模式；(3) SCP-3008 等「空间异常类」SCP 与后室的具体关联。

---

## 一、核心结论：独立宇宙，仅历史渊源

| 维度 | SCP 基金会 | 后室 |
|------|-----------|------|
| 性质 | 协作型虚构百科 | 协作型虚构创作 / 都市传说 |
| 诞生 | 2007–2008 年，源自 4chan /x/ 板的 **SCP-173（雕塑）** | 2019 年 5 月，源自 4chan /x/ 板的黄房间照片 + noclip 跟帖 |
| 叙事框架 | 「基金会」秘密收容异常（Secure, Contain, Protect）| 误入者在无限阈限空间中求生 |
| 组织方式 | 编号条目 + 收容等级（Safe/Euclid/Keter…）+ 社区评分 | 编号「层级（Levels）」+「实体（Entities）」+ 难度等级 |
| 正典 | **无单一正典**，多作者多解读 | **无单一正典**，且分裂为多套维基 |
| 平台 | scp-wiki.wikidot.com（及各语言分部，如 scp-wiki-cn.wikidot.com）| Fandom、Wikidot、Kane Pixels 宇宙、各语言分部 |

**两点必须明确：**

1. **后室不是 SCP 条目。** 后室诞生于 SCP 基金会之外的独立 4chan 跟帖，并非以「SCP-XXXX」编号收录的项目，也从不归基金会「收容」。
2. **二者无官方交叉。** 在各自的**官方设定层面**，后室世界里没有基金会，基金会的正典里也不包含后室。任何把两者写进同一故事的内容，都属于**粉丝二创（fan crossover）**，而非任一方的官方设定。

> **版本差异 / 二创提示**：网络上大量「基金会收容了后室」「后室是某个 SCP」的说法均来自非官方的粉丝维基或个人创作（例如某些 Fandom 衍生维基把后室写成一个 SCP 项目）。这些**不是 SCP 基金会或后室任一主维基的正典**，引用时务必标明其为二创。

## 二、真正的渊源：相同的「土壤」与借来的「骨架」

后室与 SCP 虽是独立宇宙，但血缘上确实同根，主要体现在三点。

### 2.1 同一发源地：4chan /x/

- SCP 基金会的第一个条目 **SCP-173（雕塑）** 同样诞生于 4chan 的 /x/（超自然）板（2007 年）。
- 后室也诞生于 /x/（2019 年）。
- 两者都是 **4chan 匿名创作文化 → 协作维基** 这一典型路径的产物。

### 2.2 借鉴 SCP 的协作百科模式

后室从一段孤立的 creepypasta，演化为系统化的层级宇宙，其**组织形式直接借鉴了 SCP 基金会**：
- **统一编号**：SCP 用「SCP-编号」，后室用「Level 编号 / Entity 编号」。
- **统一模板**：条目格式高度规范（SCP 的收容程序 / 描述；后室的层级描述 / 实体 / 出入口 / 生存难度）。
- **社区投稿 + 评分**：人人可写、由社区评价，无中心作者。
- **多作者无单一正典**：尤其是后室的 Wikidot 维基，明确效仿 SCP「不设唯一正典、允许作者间互相渗透甚至推翻彼此故事」的理念。

正因如此，主流媒体在介绍后室时，几乎都会用「**类似 SCP 基金会的协作虚构项目**」来定位它。

### 2.3 共享的恐怖母题

- 「**日常之物的异常化**」：SCP 让普通物品 / 地点变得致命；后室让普通办公空间变成无限牢笼。
- 「**官僚 / 系统化的恐怖**」：用冷静、条目化、近乎技术文档的笔触描写不可名状之物，制造反差恐怖。
- 「**阈限空间（liminal space）**」美学：后室更是把这一母题推向极致，成为整个「阈限空间」网络潮流的旗帜性符号。

## 三、空间异常类 SCP 与后室的关联

后室最直接的概念先驱，是 SCP 基金会中一类「**空间异常 / 无限内部空间**」的条目。其中影响最大、与后室关联被讨论得最多的就是 **SCP-3008**。

### 3.1 SCP-3008（无限 IKEA / The Infinite IKEA）

| 项目 | 内容 |
|------|------|
| 作者 | **Mortos** |
| 发布日期 | **2017 年 5 月 4 日**（**早于后室约两年**）|
| 收容等级 | **Euclid** |
| SCP-3008-1 | 一处外观为宜家（IKEA）卖场、却向外**无限延伸**的口袋维度；内部空间据测至少 10 km²、无可见边界，并有与卖场营业时间同步的**昼夜循环**。从正门进入并走出门视线范围者，即被传送至此空间。|
| SCP-3008-2 | 身着宜家黄蓝制服、**无脸**、身材比例怪异夸张的类人实体（「员工」）。**夜间**变得极具攻击性，一边袭击一边重复：「The store is now closed, please exit the building（本店已打烊，请离开建筑）。」白天则被动呆滞。|
| 居民 | 误入并被困者在其中自建据点、结成社群、组织防御以对抗夜间袭击。|

### 3.2 与后室的相似点（为何常被并提）

SCP-3008 与后室在母题上高度重合：

- **看似无限的阈限空间**：都向外无尽延伸，令人绝望。
- **取材日常熟悉场所**：宜家卖场 / 办公空间——熟悉感正是恐怖来源。
- **模仿人类的敌对怪物**：SCP-3008-2 会说人话；后室的部分实体（如 Skin-Stealer 窃皮者、Smiler 微笑者）也以拟人 / 拟态方式狩猎。
- **误入者求生 + 自建社群**：两者都有「被困者抱团求生、有人几近逃脱却死于途中」的母题。
- **进入即回不去**：极难逃离的封闭性。

### 3.3 关键区别

| 维度 | SCP-3008 | 后室 |
|------|----------|------|
| 进入方式 | **物理进入**——任何人走进那家宜家正门并走出门的视线即被传送 | **noclip 滑出现实**（或后期扩展的传送门 / 层级出入口）|
| 空间外观 | 单一的宜家卖场风格 | 起初是黄色办公空间（Level 0），后扩展为成百上千种不同层级 |
| 归属 | 是 SCP 基金会的**正式编号条目**，受基金会收容 | **独立宇宙**，不属于基金会，不被收容 |
| 体量 | 单一条目（及其衍生）| 庞大的多维基层级 / 实体体系 |

### 3.4 是「启发」还是「巧合」？——准确的措辞

这是最容易被夸大的一点，必须谨慎表述：

- **可以说**：SCP-3008 在「无限的、日常化的阈限空间」这一**概念上是后室的精神先驱之一**，时间上也确实早于后室（2017 vs 2019），其氛围被广泛认为对后室有**启发／影响**。
- **不能说**：没有任何官方文档（无论是 SCP-3008 条目本身、维基百科词条，还是后室主维基）明确声明「后室直接改编 / 衍生自 SCP-3008」。
  - SCP-3008 的官方条目对后室**只字未提**；
  - 维基百科的 SCP-3008 与后室词条，也**只在「另见 / See also」中互相链接**，并未陈述衍生关系。

> **准确结论**：SCP-3008 是后室在母题与氛围上的**重要先驱与公认灵感来源之一**，但二者**没有官方设定上的因果或从属关系**。把它说成「后室的直接起源」是不准确的——后室真正的直接起源是 2019 年那张 4chan 黄房间照片与 noclip 跟帖（详见《00-起源与发展史.md》）。

### 3.5 其他相关的空间 / 维度异常类 SCP

SCP 基金会中还有不少「无限 / 异常内部空间」类条目，与后室同属一脉的恐怖谱系（均为各自独立条目，与后室无官方交叉）：

- **SCP-3008** —— 无限宜家（关联讨论最多，见上）。
- 大量以「比外部更大的内部空间」「无尽走廊 / 房间」「错位维度」为母题的 Euclid / Keter 级条目。

这类条目共同构成了「**空间不可信、日常空间异常化**」的恐怖传统，后室正是站在这一传统之上、再叠加 noclip 机制与阈限美学，独立发展成型。

## 四、给读者 / 创作者的实用提醒

1. **介绍后室时**，可以说它「在协作模式上借鉴 SCP、在概念上承接 SCP-3008 等空间异常」，但**不要**说它「是 SCP 的一部分」或「出自 SCP 基金会」。
2. **看到「基金会收容后室」「后室是 SCP-XXXX」类内容**，先确认出处——几乎都是粉丝二创，而非任一方正典。
3. **区分三套以上独立设定**：SCP 基金会、后室 Fandom、后室 Wikidot、Kane Pixels 宇宙、各语言分部——它们**互不统属，版本差异普遍**，引用前先标明出处。
4. **术语对照**（首次出现给中文译名）：Level 0（黄房间 / 大堂）、noclip（滑出现实）、Entity（实体）、Smiler（微笑者）、Skin-Stealer（窃皮者）、SCP-173（雕塑）、SCP-3008（无限 IKEA）、SCP-3008-1（无限空间）、SCP-3008-2（无脸员工）。
