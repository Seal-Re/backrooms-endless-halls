# Bacteria（细菌 / 杆菌）— The Lifeform / Entity 0

> 别名：Bacteria（细菌）、The Lifeform（生命体）、Entity 0（在部分 Fandom 改编版编号为 Entity 0）
> 主要来源：**Kane Pixels（凯恩像素）后室宇宙**中的「The Lifeform（生命体）」，以及游戏《Inside the Backrooms（深入后室）》中的 Bacteria

## 概述

Bacteria（细菌）是后室中最知名的掠食实体之一，其声望主要来自 **Kane Pixels（凯恩像素）** 的后室视频系列——他当时年仅 18 岁，以高度写实的 VFX 重新诠释了后室，片中的怪物即「The Lifeform（生命体）」，俗称 Bacteria。它是一种（或一群）极度敌视人类的人形生物，会捕食一切落入其感知范围的受害者，是 **Async Research Institute（异步研究所）** 在研究后室时的重大威胁。

**版本差异**：Bacteria 横跨多个相互独立的设定体系——Kane Pixels 影像宇宙（The Lifeform）、游戏《Inside the Backrooms》、以及各类 Fandom 编号条目（Entity 0 等）。下文综合各版本，差异处会注明。

## 外观

- 极为**高大、瘦削、模糊的人形**，双足直立——据描述约 **11 英尺（约 3.35 米）** 高，轻松俯视人类。
- **由黑色「线缆/电线」缠绕构成的骨架式身体**，整体如一团缠结的黑色金属丝拧成人形。
- 两条**极长、垂到地面的手臂**，手指又细又长；**腿相对短且无脚**。
- 头部**块状、布满孔洞**，连接在人形躯干上。
- 生物学本质（Kane Pixels 版）：被暗示为**高度变异的枯草杆菌（hay bacillus / Bacillus subtilis）联合菌落**，会从后室中遍布的、类似霉菌的**黑色物质里「活过来」**。这也是「Bacteria（细菌）」之名的由来。

## 行为与威胁

- **极端敌视人类**，是受害者在 Level 0 等早期层级会遇到的第一个致命威胁（游戏中）。
- **对声音高度敏感**：能侦测走路、奔跑、跳跃、吹口哨等动静。
- **远距视力**：能从远处发现人类。
- **移动速度快**，肢体动作迅捷而安静。
- 会在后室中**看似随机地游荡**，并发出**类似人类言语的咕噜/呻吟声**，但不清楚它是否理解这些声音的含义。

## 出没层级

- 在《Inside the Backrooms》中出没于 **Lobby（大厅 / Level 0 黄房间）与 Dark Rooms（黑暗房间）**，是玩家最先遭遇的威胁。
- 在 Kane Pixels 宇宙中，The Lifeform 出现在被异步研究所探索的多个后室空间内。

## 应对方法

- **保持安静**：因其依赖听觉，**降噪、放慢脚步、不要奔跑/吹口哨**是首要生存原则。
- **利用掩体阻断视线**：避开其远距视野，利用墙体与拐角脱离视线。
- **不要正面对抗**：移动速度快且力量强，无有效反制手段，唯一可靠策略是**潜行与逃离**。
- 留意其咕噜/呻吟声判断方位，提前规避。
