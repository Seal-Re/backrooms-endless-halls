# Partygoer（派对客 / 派对者）— Entity 67

> 别名：Partygoers =)（带笑脸符号的官方页名）、Entity 67（实体67）
> 原始页：The Backrooms Wiki（Wikidot 版）「Entity 67 - "Partygoers =)"」

## 概述

Partygoer（派对客）是后室中编号为 **Entity 67（实体67）** 的一类高度智能的群居掠食实体。它们以「举办派对」的诡异姿态出现——手持气球、脸上挂着刻进皮肤的笑脸——但本质是成群结队、组织化狩猎人类的顶级掠食者。它们狩猎人类的目的有三：**当作食物、当作消遣（运动）、以及扩充自己的族群（把人类转化成派对客）**。

**版本差异**：不同 wiki 对派对客的「友善度」描述冲突很大。部分游戏改编版（如 Inside the Backrooms / Escape the Backrooms）与早期 Fandom 条目把它们描述为「友善、爱开派对」，而 Wikidot 正典版本则明确将其定性为**残忍、嗜虐、与 Phobic Centipedes（恐惧蜈蚣）同源的恶意实体**。本文以 Wikidot 正典为主。

## 外观

- 高大的双足生物，皮肤光滑、似皮革质感。
- 体色以**鲜黄色**最常见，也存在红、蓝、绿、白等变体。
- 脸上有一道**刻出来、糊着血的卡通笑脸**，其咧嘴形态与 Phobic Centipede（恐惧蜈蚣）的笑容一致。
- 方块状的腿、胸口有甲壳（carapace）。
- 标志性特征是**细长如面条的手臂，末端是布满钩状牙齿的吸盘状口器**——这是它们转化人类的关键器官。
- 手中常握着一只**红色气球**，强化「要去参加派对」的诡异观感。

## 行为与威胁

- **组织化群猎**：表现出团队智能，会协同布置精巧陷阱，懂得操作机械和计算机系统。
- **转化能力**：一旦其带牙的吸盘状肢体接触到人类皮肤，受害者就会开始**转化为派对客**。据描述，转化中**精神层面的改变近乎瞬间，肉体变化则缓慢**。
- **短距心灵感应**：彼此用短程心灵感应交流，但有一个关键限制——**心灵传输基于视觉**（看到什么才能传什么）。
- **生理优势**：皮肤**防火、抗切割与穿刺**，并能像法拉第笼（Faraday suit）一样屏蔽电流。
- **感官弱点**：它们**近视且行动迟缓**——这是逃生的关键。
- 性格嗜虐，与恐惧蜈蚣类似，狩猎兼有「取乐」成分。

## 出没层级

- 主要栖息于 **Level Fun（欢乐层 / Fun Level）**，描述为一艘**塞满派对房间的游轮**。
- 进入该层的入口被刻意用错误信息（误导宣传）掩盖。
- 在游戏改编（Inside the Backrooms 等）中，派对客出现在 **Abandoned Office（废弃办公室）层的「派对房」** 解谜场景里。

## 应对方法

| 该做 | 不该做 |
|------|--------|
| **立刻逃跑**——它们近视且移动慢 | 犹豫、迟疑 |
| 被咬（接触）后**立即上报**转化风险 | 假定它们友善而靠近 |
| 必要战斗时，**砍断它们的手臂**迫使其进入狂暴态，再攻击头部 | 与成群派对客正面交战 |

- 由于其心灵感应**依赖视觉**，破坏视线/在视野受阻处行动可削弱其协同。
- 注意：袭击者常在受害者察觉前就已动手（受害者往往看不到攻击源）。
