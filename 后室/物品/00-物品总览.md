# 后室（Backrooms）物品总览

> 本文汇总后室中最知名、最具代表性的物品（Objects）。后室是社区协作创作，存在多个 wiki 版本，设定常有冲突。本文以 **Wikidot 新版**（backrooms-wiki.wikidot.com，目前最受认可的「正典」）为主轴，辅以 **Fandom 旧版**、**Miraheze 镜像** 与 **中文 Wikidot/Fandom** 交叉印证；发现冲突时标注「版本差异」。
>
> **术语约定**：物品名首次出现给中英对照，如「Almond Water（杏仁水）」。「流浪者（Wanderer）」指误入后室的人类；「前厅（Frontrooms）」指现实世界；「M.E.G.」即 The Major Explorer Group（主要探索者组织），后室中最大的探索/记录组织。

---

## 关于「物品编号」的版本差异（重要）

后室不同 wiki 的物品编号体系**互不兼容**，同一编号在不同版本指代完全不同的东西。下表以「Liquid Pain（液态痛苦）」为例说明：

| 物品 | Wikidot 新版编号 | Fandom 旧版 / Miraheze 编号 |
|------|------------------|------------------------------|
| Almond Water（杏仁水） | Object 1 | Object 1 |
| Liquid Pain（液态痛苦） | **Object 48** | **Object 12** |
| Mortality Shards（凡命碎片） | Object 12 | — |
| Firesalt（火盐） | Object 15 | Object 15 |

> **版本差异**：引用编号时务必注明来源 wiki。本文档各物品标题同时给出主要版本的编号。

## Almond Water（杏仁水）— Object 1

> 详见单独文件 [`01-杏仁水-Almond-Water.md`](01-杏仁水-Almond-Water.md)。

- **外观**：约 1 英尺高的金属保温瓶，盛 2–4 杯清澈液体，瓶身常有凹痕划痕。
- **作用**：单瓶约 600 卡路里，三瓶满足成人一日所需；具再生/治愈特性，可中和敌对实体造成的效果，是后室**头号补给品**。同时是后室**最通用的标准货币**。
- **颜色变种**（Wikidot 版）：灰（最常见、营养最高）、绿（咖啡因、提神、易成瘾）、红（苦、抗生素效果、治疫疾、过量致癌）、蓝（助眠、抗焦虑抑郁、过量永久成瘾）。
- **获取**：绝大多数层级自然出现，定居地可交易购得。
- **警告**：勿饮半空瓶（可能被污染/掺毒）；某些层级杏仁水带氰化物般毒性，「拿不准就煮沸」。

## Smiler Repellent（微笑者驱避剂）— Object 3

- **外观**：近乎透明的液体，外观酷似杏仁水；据信由杏仁水加若干未知成分混合而成，配方几乎无从查证。
- **作用**：极小一滴即可清空半径约 20 米内的 **Smiler（微笑者，后室最危险实体之一）**；被其效果波及的微笑者会长时间虚弱；若直接接触，微笑者会**当场消失且无返回记录**。
- **获取**：极度稀有，正被各方不惜代价搜集但收效甚微；已与 **The Lost（迷失者，一支神秘流浪者派系）** 达成协议以获取该液体。
- **来源 wiki**：Wikidot 新版。

## Deuclidators（解欧化器 / Warplooms）— Object 4

- **外观**：长约 0.25 米的灰色矩形机械，外壳有一个投料口、两个旋钮和一个蓝色按钮，并有外露的线材手柄；内部上层为大小齿轮，下层为电池与约 300 根可高频振动的「织机弦」。
- **作用**：通过让弦以目标材料的原子振动频率振动，产生引力效应，使「周围区域在不缩小尺寸的前提下显著拉近」，满电时作用距离约 50 米。用于地形穿越、战斗与逃生。
- **燃料**：投料口接受多种材料，效率排序为 rhinestone（仿钻）> 铜 > 橡胶 > 纸（极低效）。
- **获取**：初见于 Level 5 的补给箱；**B.N.T.G.** 组织逆向工程约一年后已能量产，估计现存约 350 台（其中至少 320 台为人造）。
- **警告**：频繁使用会引发忧郁与恶心，建议每日不超过 20 次、晕船者慎用；在 Reality Fresheners（现实清新剂）附近会完全失效。

## The Mirror（镜子）— Object 6

> 详见单独文件 [`06-镜子-The-Mirror.md`](06-镜子-The-Mirror.md)。

- **外观**：Level 0 某隐秘房间内、绿色出口标志下的大型矩形挂镜，约 97.1 英寸高 × 61.9 英寸宽，底部铭牌写着「REALITY / 1 Cori 13 | 12」（含义未解）。
- **作用**：注视数小时后，多数人会在镜中看到自己在**前厅往昔生活**的温馨场景（家、亲人、宠物），但无法互动；摄像设备拍不到异常；在后室出生者只看到普通镜像。
- **特性**：不可刮花、不可破坏、不可移除。
- **警告**：强烈不建议攻击它——它会防御性反击，曾有队员手部无视物理（no-clip）穿过镜面后染上罕见麻风病。

## Liquid Pain（液态痛苦）— Object 48（旧版 Object 12）

> 详见单独文件 [`48-液态痛苦-Liquid-Pain.md`](48-液态痛苦-Liquid-Pain.md)。

- **版本差异**：Wikidot 新版为 **Object 48**，将其设定为「盐酸 + 氰化钾」的伪装成杏仁水的剧毒液；Fandom 旧版/Miraheze 为 **Object 12**，强调其深红色、pH 约 1–2 的强腐蚀性，并会随暴露空气固化为「Crystalized Pain（结晶化痛苦）」。
- **作用/危害**：剧毒、强腐蚀；误饮致胃酸灼伤、器官衰竭、死亡。Wikidot 版强调其**外观几乎与杏仁水无异**，仅略带苦味与红色调，是后室「陷阱型」物品的代表。
- **出没**：Wikidot 版记录于 Level 46（无尽沙漠），半埋于沙中夹杂在普通杏仁水瓶之间；旧版称可在小水洼/水池自然形成或装于金属保温瓶。

## Firesalt（火盐）— Object 15

> 详见单独文件 [`15-火盐-Firesalt.md`](15-火盐-Firesalt.md)。

- **外观**：橙色半透明晶体碎片，1–5 cm；人造大型「火盐锭」呈暗红、更透明。熔化后变为无色易燃液体「pyroil（火油）」，气味类似熏香。
- **物理性质**：莫氏硬度 7、易碎；熔点约 47℃；溶于水/杏仁水并放热；冲击时碎裂放出强光与高热，即便低氧也能燃烧。
- **作用**：自卫武器（小晶体可造成一二级烧伤，>50–100g 的火盐锭爆炸威力可达同质量炸药约一半）；寒冷层级的**热源**与快速煮食/煮水手段；火油可作汽油替代燃料。对 **Smiler（微笑者）** 等实体尤其有效（Fandom 版强调）。
- **获取**：小晶体在前 5 个层级的墙角生长，Level 0 罕见；大型火盐锭需熔合多块晶体人工制成。

## Royal Rations（皇家口粮）— Object 16

- **外观**：后室独有的白色可食用凝胶，无腐败迹象。
- **作用**：极小份量即等同三顿正餐的营养；食用者形容是「此生吃过最好吃的东西」，口味因人而异（从微甜到「神之盛宴」）。**但凡食用超过一勺者会产生对它的强烈渴求（craving）**——化学检测排除了已知成瘾药物，但因样本不断离奇消失而无法完整分析。
- **出没/获取**：Level 4 事件后数日首次在 **Level 23** 被发现；**Level 56** 曾出现 297 个标着「Exodus 3:8（出埃及记 3:8）」的无特征箱子，多支队伍围攻两天后所有包裹全部失踪。无已知生产方法，多通过与神秘组织的关系获得。
- **意义**：其强迫性渴求副作用使它无法成为解决后室食物短缺的方案。

## Liquid Silence（液态寂静）— Object 17

- **外观**：黑色黏稠物质，取自被摧毁的 **Scream Eater（尖叫吞噬者）** 实体。
- **核心特性**：每一粒液态寂静都含一个**口袋维度**，可按体积比例储存声音——1 升可储存高达 191 分贝（约相当于一枚手雷）；施加 ≥1 伏电压会令口袋维度坍缩，在微秒内释放储存的声音。0℃ 以上会干燥成黑粉但仍保留吸音性。**大量该液体可在 30 米半径内令实体与流浪者陷入极度恐惧。**
- **作用**：与金属结合制造静音工具（橡胶鞋底、撬棍、枪械部件）；武器化（89 升 ≈ 1 吨 TNT）。
- **出没/获取**：仅见于 **Level 93**，只能从被摧毁的尖叫吞噬者身上采集，单只仅产 40–50 升，极度稀有，通常只有大型有影响力的组织才能接触到纯品。

## Babel Balm（巴别香膏）— Object 25

- **外观**：装在无标签红色胶管里的半透明白色膏体，外形像普通润唇膏，管长 4–8 cm、宽不超过 2 cm，膏体会**发出微弱可见光**。
- **作用**：抹于唇上/近唇处后，**无论说何种语言，听者都会听到自己的母语**；抹于纸质文件上则文字对任何读者可读（仅限印刷/手写，对数字媒介无效）。效果持续 10 分钟至 2 小时，视涂抹质量而定。
- **出没/获取**：最常在 Level 0、3、4、11 的地面发现；探索者用于哨站沟通、交易和帮助新到的流浪者。
- **局限**：对实体无效——很多实体「没有嘴唇」。也可当普通润唇膏用，味道类似 Chapstick。

## Super Almond Water（超级杏仁水）— Object 100

- **本质**：一篇**元叙事（metafiction）**条目，而非常规物品说明。它讲述杏仁水「据称」进化为可治愈一切伤病的万灵药、并能灭杀实体。
- **真相**：Nick Kevorkian 策划了一场协同宣传，企图让流浪者相信杏仁水已变成「超级杏仁水」，以**测试集体信念能否改变现实**。计划「成功」了，但饮用者却出现严重神经损伤并死亡，与承诺的疗效完全相反。
- **意义**：质疑后室中机构信息（包括 M.E.G. 公告）的可靠性，是后室「belief shapes reality（信念塑造现实）」母题的代表作之一。

## Royal Carpet（皇家地毯）

> **正典状态说明（版本差异 / 来源存疑）**：在当前主流后室 wiki 的**官方物品索引中均未收录**名为「Royal Carpet」的标准物品——包括 Wikidot 新版的 Objects 索引（Object 1–100+）、Miraheze 镜像的 Object List，以及搜索 Fandom 主站均无对应正典条目。
>
> 与「Royal/Carpet」相关的真实条目反而是**层级（Levels）而非物品**，例如：
> - **Level 666「The Red Carpet（红地毯）」**（Backrooms Freewriting Wiki）——铺满柔软干燥红地毯、配洁白混凝土墙的层级。
> - **Level 1779「Carpet Maw（地毯之喉）/ Red Gullet」**（Backrooms Freewriting Wiki）——铺着厚重深红地毯的异常细长走廊。
> - **Level 258「Rugs of Faith」**（Backrooms Freewriting Wiki）。
> - 另有「Royal Rations（皇家口粮，Object 16）」名称相近但完全无关。
>
> 因此，「Royal Carpet」很可能源自某个**衍生游戏 wiki 或小众/非正典创作**，而非主流后室正典。为遵守「不编造不存在的条目」的原则，本文不为其虚构外观/作用/层级等设定。若你指的是上述某个地毯主题层级或某个特定游戏（如 Roblox 的后室同人游戏）中的道具，请提供来源以便补全。

## Lavender Water（薰衣草水）

> **正典状态说明（版本差异 / 来源存疑）**：与 Royal Carpet 类似，「Lavender Water」在 Wikidot 新版与 Miraheze 的官方物品索引中**均无独立标准条目**。它常被联想为 Almond Water（杏仁水）的某种「变体水」，但主流正典杏仁水的官方变种是按**颜色**（灰/绿/红/蓝）划分的效果变种，并不存在官方命名的「Lavender Water」。
>
> 此外，「Lavender Waters」是另一作品 **Yume 2kki（梦日记同人游戏）** 中的一处地点（一片宁静的湖泊），与后室无关，搜索时易混淆。
>
> 因此「Lavender Water」很可能来自**某个后室衍生游戏或小众 wiki 的自创道具**（这类设定通常赋予其「安抚实体 / 助眠 / 净化精神」一类功能，但缺乏主流正典依据）。本文不为其编造具体设定。若你指的是某游戏内道具或某特定 wiki 条目，请提供来源以便准确补全。
