# Object 15：Firesalt（火盐）

> 后室中可爆燃的晶体物质，既是流浪者对抗实体的**自卫武器**，也是寒冷层级的**热源**与**燃料**来源。本文以 **Wikidot 新版**与**中文 Wikidot** 为主，辅以 Fandom 旧版交叉印证，并标注「版本差异」。

---

## 基本信息

| 项目 | 内容 |
|------|------|
| 编号 | Object 15（各主流 wiki 一致） |
| 别名 | 火盐、Firesalt；熔化态称 **pyroil（火油）** |
| 类型 | 挥发性晶体（具热致负熵 / ectoentropic 性质——Fandom 版） |

---

## 外观

- 天然形态：**橙色、略透明**的不规则晶体碎片，大小 **1–5 cm**。
- 人造形态：熔合多块晶体制成的大型「**火盐锭（ingot）**」，呈**暗红色、透明度更高**。
- 熔化态 **pyroil（火油）**：无色易燃液体，**气味类似熏香（incense）**。

---

## 物理性质

| 性质 | 数值 / 描述 |
|------|------|
| 硬度 | 莫氏硬度 **7**（耐刮但易碎） |
| 熔点 | 约 **47℃**，到达即熔为 pyroil（火油） |
| 溶解性 | 溶于水和杏仁水，**溶解时放热** |
| 燃烧 | 即使在**低氧环境**也能高效燃烧 |
| 反应 | 受冲击会碎裂，释放**强光与高热** |

---

## 威力与用途

### 武器（自卫）
- 小晶体投掷时，直接命中可造成人类**一至二级烧伤**；可制成「火爆竹」用于突袭、惊吓或驱离敌对实体与人类。
- 大型火盐锭（质量 >50g / 100g 级别）可像炸药一样**爆炸**：每 100g 释放的能量约相当于同质量一根炸药管的一半。组织会将其用作正式武器。
- **对抗实体**：**版本差异**——Fandom 旧版明确指出，因其燃爆特性，火盐是对付 **Smiler（微笑者）** 及大多数其他实体的**极有效武器**；Wikidot 新版侧重描述其对人类的烧伤/爆炸物理效果，未特别点名某种实体。

### 生活用途
- **热源**：在寒冷层级取暖。
- **快速煮食/煮水**：可用于快速煮沸食物或为杏仁水消毒（杏仁水文档建议「拿不准就煮沸」）。

### 燃料
- **pyroil（火油）** 可作汽油替代品，为车辆供能或驱动发电机。

---

## 出没层级与获取

- 天然小晶体在**后室前 5 个层级的墙角（corners）** 生长，**Level 0 中较稀有**。
- 大型爆炸性火盐锭无法天然找到，需将多块小晶体**熔合人工制成**。

---

## 警告

- 易碎且受冲击即放热/燃爆，储存与携带需防剧烈撞击。
- 大型火盐锭爆炸威力可观，非专业人员误操作风险高。
