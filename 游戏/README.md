# 后室·无尽回廊（Backrooms: The Endless Halls）

一款基于本仓库 `后室/` 知识库制作的**单文件离线文字生存游戏 / 互动小说**。

## 怎么玩

**双击 `后室-无尽回廊.html`**，用浏览器打开即可。零依赖、离线、无需安装。

- 点选项推进剧情；顶部状态栏显示当前层级、口渴、杏仁水数量与理智提示。
- 三个开局任选：仓库夜班 / 校园走廊 / 酒店电梯（高难）。
- 底部按钮：手动存档 / 导出存档（复制存档串）/ 导入存档 / 闪烁开关（关 CRT 闪烁）。每步自动存档；死亡清档。

## 核心机制

- **理智 Sanity（隐藏）**：不显示数字，用感官反馈表达（嗡鸣→喊你名字→分不清真假）。越低叙事越不可靠。
- **杏仁水多变体**：灰（营养）/绿（提神但成瘾）/红（药用驱剥皮者，有冷却）/蓝（稳理智）。稀缺资源，忌挥霍。
- **实体规避**：每层实体不同、规避规则不同（Hound 循声/Smiler 不可直视/剥皮者用镜子验明/派对客绝不加入…）。**套错规则即死**。
- **多结局**：10 个结局，由你的旗标 + 理智 + 物品 + 同伴信任 + 所在层级共同决定（逃回前厅·真结局 / 困死阈界 / 成为后室一部分 / 被剥皮者取代 / 加入 M.E.G. / 永坠循环 / 抵达终焉…）。

## 层级（10 层）

L0 阈界 → L1 宜居地带 → L2 废弃公共带 → L3 发电站 → L5 恐怖旅馆 → L6 熄灯 → Level Fun 欢乐层级 → Level ! 不想死就快跑 → Level ∞ 无限层级 → The End 终焉。

## 开发 / 构建

源码在 `src/`（内容 data 与逻辑 engine 分离）：

```
src/
  engine.js          纯逻辑（状态机/效果/RNG/sanity/存档），无 DOM，可测
  ui.js  style.css  index.template.html   浏览器层
  data/  items entities orgs endings starts boot + levels/*.js
  engine.test.mjs    引擎单元测试（node --test）
  lint.mjs           静态校验（goto/结局可达/物品合法/死节点）
  test.mjs           1500 局随机漫游（0 崩溃/0 死胡同）
  build.mjs          内联构建 → 单 HTML
```

改完内容后重建：
```bash
node src/lint.mjs && node src/test.mjs && node src/build.mjs
```
无 Node 时用 `build.ps1`（PowerShell 回退构建）。

设计与调研：`设计-后室无尽回廊.md`、`计划-后室无尽回廊.md`、`调研-现有游戏与引擎.md`。
