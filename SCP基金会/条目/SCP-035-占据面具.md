# SCP-035（占据面具 / Possessive Mask）

> 一具会「夺舍」的瓷质戏剧面具——它高度聪慧、极具魅力，却能通过纯粹的言语操纵让人崩溃乃至自杀。SCP 基金会中经典的「智慧型危险造物」。

## 项目编号
SCP-035

## 项目等级
Keter（要塞级）

> 说明：作者为 **Kain Pathos Crow**（早期核心作者之一）。Keter 反映其极难安全收容：腐蚀液持续渗出、具备占据宿主与心理操纵能力。

## 特殊收容措施
- SCP-035 被密封在一个**玻璃罩**内（玻璃是少数几乎不受其腐蚀液侵蚀的材料），置于一间带屏蔽的房间中，房门**三重上锁**并由武装警卫看守。
- 除非进行转移或实验，否则不得开启玻璃罩。
- 严格限制与之接触 / 交谈的人员（防止心理操纵）。

## 描述
- SCP-035 外观是一具**白色瓷质的喜剧面具（comedy mask）**，但**有时会变为悲剧面具（tragedy mask）**。
- 异常之处：当它改变外观时，**所有已存在的视觉记录（照片、录像等）也会自动改变**以反映其新外观——即它能追溯性地篡改影像记录。

### 腐蚀液
- 面具的眼孔与口孔会**持续渗出一种高度腐蚀性、退化性的粘稠液体**。
- 任何接触到该物质的东西都会随时间**逐渐腐烂分解**（速率取决于材料），最终化为一滩与原污染物相同的液体；它能熔穿钢铁与血肉。
- **玻璃**是少数几乎免疫的材料，因此用作收容容器。正是这种腐蚀液最终摧毁宿主身体，迫使面具寻找新宿主。

### 占据（夺舍）机制
- 当 SCP-035 被戴到人脸上时，它会发出一种**替代性的脑波模式**，**覆盖并「熄灭」原宿主的脑波**，从而完全接管身体。
- 被占据者的身体会**加速腐烂**，最终成为木乃伊状。即便宿主身体腐败到机械上**已无法运动**，SCP-035 仍能维持认知与控制。

### 智能与心理操纵
- 实体表现出**超凡的智力**——在所有智力与能力测验中得分位列**第 99 百分位**；具备过目不忘的记忆力和强大的魅力。
- 但其本质极具**操纵性**：仅凭交谈就能造成心理伤害，档案记载它曾**诱使一些人自杀**。
- 附录 035-03 确认其具备**心灵感应（telepathic）能力**，可侵入他人的潜意识。

## 附录与故事
- **升级现象**：较新的附录描述了 SCP-035 周围不断升级的异象——分泌的血液 / 液体自行排列成仪式性的图样、对附近人员造成强烈心理影响、以及收容结构的逐渐退化。
- **作者**：Kain Pathos Crow。SCP-035 是「会说话、会操纵、远比人类聪明」的危险智慧型 SCP 的代表作之一，常与 SCP-079 等并列讨论「智慧类」威胁。

> 版本差异提示：喜剧 / 悲剧面具的切换、影像自动篡改、腐蚀液速率、占据后宿主木乃伊化的细节，在 Wikidot 现行版（已经历多次重写 / rewrite）与各 Fandom 镜像间存在措辞差异；早期版本与现行重写版在叙事语气与附录数量上差别较大。
