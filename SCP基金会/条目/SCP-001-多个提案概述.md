# SCP-001（多个提案概述 / The Multiple Proposals）

> SCP-001 是整个 SCP Wiki 上编号最靠前、地位最特殊的「条目」。它**不是**单一条目，而是**几十个相互竞争、互相矛盾的「提案（proposal）」集合**——每个提案都自称是「真正的 SCP-001」。

## 项目编号
SCP-001

## 项目等级
（因提案而异；不同提案给出 Safe / Euclid / Keter / Apollyon / Thaumiel 等各种等级，乃至「无法分类」）

## 核心概念：以多充一的「隐藏机制」
- SCP-001 被设定为基金会**最高优先级、最高机密**的项目。
- 官方页面解释：为了**掩盖 SCP-001 的真实本质**，基金会**故意创建了多份「虚假的 SCP-001 文件」与真实文件并列存放**——「several/no false SCP-001 files have been created alongside the true file/files」。换言之，**究竟哪一个（或哪几个，或一个都不是）才是真的，永远无法确定**。
- 因此在**正典（canon）层面**，SCP-001 没有唯一答案：每个提案都是一位（或多位）作者对「基金会的起源 / 世界的真相 / 第一个异常是什么」这一终极问题的独立回答。它们**彼此冲突**正是设计本意——这是 SCP Wiki 最大规模、最长期的**版本差异**集合体。
- 写作规则上，发表 SCP-001 提案被视为社区里的「荣誉 / 里程碑」，门槛与关注度极高。

## 提案数量
截至本资料整理时，官方 SCP-001 中枢（hub）共列出约 **63 个提案**，按发布时期分为多个「系列（Series）」（Series 1 至 Series 10）。下面按系列列出全部提案及其作者与昵称，并对若干最著名者展开说明。

## 著名提案速览（重点）

| 提案 | 作者 | 核心设定 |
| --- | --- | --- |
| **The Gate Guardian（门卫）** | Dr. Clef | 一个巨大的、被基金会拼命「围困」住的天使般实体。它守在伊甸园门口，挥舞燃烧之剑——但真相反转：基金会拦着它，是因为一旦放它进去，它将「重置」整个人类文明。SCP-001 最古老、最经典的提案之一。 |
| **The Prototype（原型）** | Dr. Gears | 基金会收容的「第一个」异常，奠定整个组织存在意义的源头式条目，风格冷峻克制。 |
| **The Scarlet King（猩红之王）** | Tufto | 引入 SCP 神话中最著名的反派之一「猩红之王」及其新娘、「破碎之神」叙事，连接大量衍生条目，是 K 级（K-Class）世界末日情景的核心来源。 |
| **When Day Breaks（破晓之时）** | S. D. Locke | 太阳被某种东西「替换 / 感染」，**阳光直射即死**，人类只能躲在阴影里苟活。氛围恐怖、影响极广，衍生出整个「When Day Breaks」正典宇宙。 |
| **Sheaf of Papers（一叠文件）** | Jonathan Ball | 最早的 001 提案之一：SCP-001 就是「记录其他所有 SCP 的那叠纸」本身，元层面地探讨「记录即收容」。 |
| **Thirty-Six（三十六）** | Djoric/Dmatix | 与犹太教「三十六义人（Lamed Vav）」传说相关，维系世界存续的隐秘存在。 |
| **The Lock（锁）** | qntm | 以极简冷峻笔法描写一把维系某种封印的「锁」，qntm（《反模因部门》作者）风格代表。 |
| **God's Blind Spot（神的盲点）** | Spike Brennan | 探讨基金会为何能存在于「神 / 更高存在」的注意力盲区。 |

## 附录与说明
- **没有「官方正确答案」**：SCP-001 的设计哲学就是「真相被刻意隐藏在众多假象中」。读者可以选择自己最认可的版本，但 SCP Wiki **不裁定**哪个为真——这是整个站点最大的开放式叙事。
- 各提案分属不同**正典（canon）**，彼此世界观常不兼容（例如「猩红之王」体系与「When Day Breaks」体系互不统属）。这是预期内的**版本差异**，并非错误。

> 版本差异提示：SCP-001 提案数量持续增长（本资料整理时约 63 个），未来会有更多新增；不同 Fandom 镜像、TV Tropes 等三方站点收录的提案清单常滞后于 Wikidot 官方 hub，且对各提案昵称的译法不一。本文清单以 Wikidot 官方 SCP-001 中枢页面为准。
