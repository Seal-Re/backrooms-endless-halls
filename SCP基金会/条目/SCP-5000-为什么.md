# SCP-5000（为什么？ / Why?）

> SCP Wiki 5000 竞赛的第一名作品，被公认为站点最负盛名、最具冲击力的「叙事型 / 故事驱动」条目之一。它表面是一件平平无奇的安全级装置，实则是一个层层揭开的末日真相故事——核心悬念就是那个标题：**为什么基金会要灭绝全人类？**

## 项目编号
SCP-5000

## 项目等级
Safe（安全级）

> 说明：作者为 **Tanhony**。等级标为 Safe 是刻意的反讽——真正可怕的不是这件装置本身，而是它所**承载、揭露的真相**。

## 描述（装置本体）
- SCP-5000 是一套现已**失效**的机械套装，名为「**绝对排除护甲（Absolute Exclusion Harness）**」，由**基金会自己**设计制造。
- 它曾具备异常防护功能，因过往损坏，现主要充当一个**文件存储装置**（其内部硬盘保存着大量记录）。
- 核心异常能力：为穿戴者提供一种**感知过滤（perception filter）**——其他存在（包括人类与 SCP 实体）**无法在意识上识别 / 注意到穿戴者的存在**，尽管技术上「看得见」他。这等于近乎完全的隐形。

## 叙事 / 剧情主线
SCP-5000 不是传统的「收容档案」，而是通过主角的求生与从护甲中恢复的档案，逐步拼出一个真相：

1. **大屠杀开场**：基金会技术员 **Pietro Wilson（皮耶罗·威尔逊）**在 **Exclusionary Site-06（排除站点 06）**工作时，一支机动特遣队（MTF）突然变成「基金会处决队」，开始无差别屠杀站内所有员工。Pietro 靠穿上「绝对排除护甲」（即后来的 SCP-5000）才得以隐形逃生。
2. **逃亡与调查**：Pietro 穿着护甲前往 Site-19 试图弄清状况，沿途从恢复的档案中发现一个惊天事实——**O5 议会（O5 Council，基金会最高决策层）已向全人类宣战**，主动释放被收容的异常以系统性地灭绝整个文明。
3. **被武器化的 SCP**：档案记录了基金会如何把收容物变成灭世武器——例如通过社交媒体传播 **SCP-096（害羞的人）**的图像、用 **SCP-169** 引发海啸、释放 **SCP-682（不灭孽蜥）**等等。他目睹**全球超自然联盟（GOC）**等组织的有组织抵抗逐一崩溃。

## 核心揭示：「为什么？」
故事的标题就是贯穿全篇的问题——**基金会为什么要灭绝它本应保护的人类？**最终揭示如下：

- **PNEUMA 计划**：O5 议会启动了「PNEUMA 计划」，试图绘制**人类集体意识 / 集体无意识**的图谱。
- **真正的敌人「IT（它）」**：测绘揭示出一个寄生在**人类集体无意识**中的、具感知能力的**模因实体（memetic entity）**，被称为「IT / 它」。它**腐蚀**人类的道德、共情等特质，并**以痛苦为食**。
- **比死亡更可怕的命运**：该实体造成了一种被编号为 **SCP-2718** 的存在状态——**每一个死去的人类，意识都不会消散，而是被永远困在自己正在腐烂的尸体里，持续感受躯体逐渐腐坏直至化为无法形容的永恒剧痛**，而「IT」就靠吞食这无尽的苦难存活。亿万死者都在经历这种永世折磨。
- **灭绝即慈悲**：基金会因此判定——**让全人类彻底灭绝，反而是一种慈悲**。只有当所有被感染的人类都死去、不再有新的痛苦供养，「IT」才会消失，**所有已死之人才能从永恒折磨中解脱**。这就是「为什么」。

## 结局与反转
- Pietro 抵达存放「SCP-579」的 Site-62C 时，他最后的日记戛然而止于一句：「**Oh … so that's how it is.（哦……原来如此。）**」
- **最终反转**：护甲内被发现的，是**现任基金会员工 Pietro Wilson 本人的尸体**——而与此同时，Pietro 却仍**活生生地**在 Exclusionary Site-06 工作。这揭示了一个残酷真相：**「IT」借助 Pietro 成功重置了时间线**。也就是说，基金会的灭绝行动**失败了**：未能杀光所有被感染的人类，「IT」没有消失，时间线被回滚——人类如今**再无希望**，每一个死者都将加入亿万同胞，在无死亡的永恒苦痛中沉沦。

## 附录与故事
- **作者**：Tanhony。SCP-5000 以「基金会反派化 + 比死亡更恐怖的真相 + 西西弗斯式的失败结局」奠定了其在 SCP Wiki 上的传奇地位，催生了庞大的衍生与解读社区。
- **关于「SCP-579」「SCP-2718」**：二者本身是站点上独立的、刻意保密 / 「访问被拒绝」式的恐怖条目；SCP-5000 借用它们作为揭示真相的拼图，体现了 SCP Wiki 条目互文（cross-link）的叙事手法。

> 版本差异提示：以上剧情解读综合自 Wikidot 原文及社区共识（含 5K 衍生 wiki、解说）。条目本身以「档案碎片 + 留白」呈现，许多细节（如 IT 的确切本质、PNEUMA 全貌）官方刻意不写满，不同读者 / 镜像的解读在措辞上有差异，但主线（基金会为终结由集体无意识寄生体造成的永恒死后折磨而灭绝人类、并最终失败）为社区公认。
