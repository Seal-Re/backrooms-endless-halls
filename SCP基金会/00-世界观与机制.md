# SCP 基金会 · 世界观与机制总览

> 本文档为 SCP 基金会（SCP Foundation）整体设定的入门与机制参考。SCP 基金会是一个开放式协作创作（collaborative fiction）项目，没有单一官方正典——各 wiki 版本（英文 Wikidot 主站、中文分部 scp-wiki-cn、Fandom 旧版镜像、各语言分部）以及不同作者之间，设定常有冲突。本文以 **scp-wiki.wikidot.com（英文主站）** 与 **scp-wiki-cn.wikidot.com（中文官方分部）** 为准，遇到版本差异会专门标注。

## 一、SCP 基金会是什么

**SCP 基金会（The SCP Foundation）** 是虚构设定中的一个秘密超国家组织。它的存在凌驾于各国政府之上，且不受任何单一政府管辖，目的是**搜寻、收容、研究、控制一切"异常"（anomalous）现象、物品、生物与地点**，从而维护"常态"（Normalcy）——即让全人类继续相信世界遵循它"应当"遵循的科学规律。

核心设定要点：

- **守护"帷幕"（The Veil / Masquerade）**：基金会的首要使命之一是隐瞒异常的存在，使公众生活在一个"正常"的世界里。绝大多数行动的目标不是消灭异常，而是把它**藏起来**并防止其知识扩散。
- **不是英雄，而是必要之恶**：基金会自我定位为冷酷、务实的官僚机器。为了控制异常、保护人类整体，它会做出在道德上极具争议的牺牲（例如使用 D 级人员做高危实验）。这种"道德灰度"是 SCP 文学的核心基调。
- **与其他组织（GoI）共存**：世界上还存在许多"相关组织"（Groups of Interest, GoI），如混沌分裂者（Chaos Insurgency，从基金会叛逃）、全球超自然联盟（Global Occult Coalition，倾向消灭异常）、蛇之手（Serpent's Hand）、马歇尔卡特和达克公司（Marshall, Carter and Dark）等。它们与基金会有合作、竞争或敌对关系。
- **"SCP"一词的双关**：每个被收容的异常都用 `SCP-####` 编号命名（如 SCP-173）。SCP 既是项目编号的前缀，也是基金会宗旨三词的缩写。

### 口号 / 宗旨：Secure, Contain, Protect

基金会的座右铭是三个 S-C-P 开头的英文词，中文分部官方译法为「**控制、收容、保护**」：

| 英文 | 中文官方译名 | 含义 |
|------|------------|------|
| **Secure** | 控制 | 主动搜寻并"获得"异常，将其纳入掌控，防止落入敌对方手中 |
| **Contain** | 收容 | 把异常关押、隔离、稳定，使其无法对世界造成破坏或泄露 |
| **Protect** | 保护 | 保护人类（以及在必要时保护异常自身）免受彼此伤害，维护常态 |

> **术语提示**：座右铭中的 Contain 对应"收容"，而项目编号 SCP 中的 C 同样是 Contain。"Special Containment Procedures（特殊收容措施）"既是 SCP 的全称展开，也对应每个项目档案中那一段描述如何关押该异常的核心文本。

## 二、收容等级 / 项目等级（Object Classes / Containment Classes）

**项目等级（Object Class）衡量的是"收容难度"，而非"危险程度"。** 一个 Keter 级项目不一定比 Safe 级更致命——它只是更难被可靠地关住。这是最常见的设定误读，务必注意。

> **版本差异**：在新的「异常分类系统（ACS）」中，"Object Class"被更名为"**Containment Class（收容等级）**"，并把 Thaumiel 等从主等级降为"次要等级 / 神秘等级（Secondary / Esoteric Class）"。下文先按传统主流叙述，再在第三节讲 ACS。

### 主要等级（Primary Classes）

| 等级 | 中文译名 | 定义 |
|------|---------|------|
| **Safe** | 安全 | 容易且安全地被收容。通常因为基金会已充分研究该异常，或它需要特定、蓄意的激活/触发才会表现异常。**注意：Safe 不代表操作它时没有威胁**——例如一把"碰到就杀人但锁进盒子就完全无害"的刀也是 Safe。 |
| **Euclid** | 欧几里得 | 需要更多资源才能完全收容，或收容并不总是可靠。通常因为对它理解不足或其本质不可预测。**所有具自主性、感知力或智能的实体默认归为 Euclid**，因为它们能自主思考行动，带来固有的不可预测性。 |
| **Keter** | 克特尔 | 极难持续、可靠地收容，收容措施往往大规模且复杂，常因基金会缺乏理解或技术手段。**Keter 不等于危险**，只代表收容代价极高或收容极易失败。 |
| **Thaumiel** | 索马里 / 陶米尔 | 基金会**反过来用来收容或对抗其他 SCP** 的异常。其存在本身属最高机密，位置、功能、状态只有 O5 议会和极少数高层知晓。（ACS 中归为次要/神秘等级。） |

> **"密封盒测试（Locked Box Test）"** 是判断主等级的非正式经验法则：把异常单独锁进一个盒子里——若它安然无恙 → Safe；结果不确定 → Euclid；它能轻松逃出来 → Keter；它本身就被用来当作收容工具 → Thaumiel。

### 次要 / 神秘等级（Secondary / Esoteric Classes）

| 等级 | 中文译名 | 定义 |
|------|---------|------|
| **Apollyon** | 亚伯廉 / 毁灭 | **无法被收容**、预计即将不可避免地突破收容，或将引发某种世界末日（K 级情景）。极其罕见，往往意味着结局已不可逆。 |
| **Archon** | 执政官 | 理论上可以收容，但出于某种原因**最好别去收容**（强行收容反而更糟）。基金会主动选择"不关"。 |
| **Cernunnos** | 科尔诺斯 | 功能上能收容，但当下因后勤或伦理考量、收益不抵成本而**选择暂不收容**。 |
| **Ticonderoga** | 提康德罗加 | **既无法收容、也无需收容**——与 Archon 不同的是它是真正"关不住"（如无所不在或外星起源），而非主动选择不关。 |

> 以上次要等级（Archon / Cernunnos / Ticonderoga 等）属较新且使用频率不高的设定，许多老条目并不采用。属于典型的**版本/作者差异**。

### 非标准 / 状态等级（Non-Standard Classes）

| 等级 | 中文译名 | 定义 |
|------|---------|------|
| **Neutralized** | 已无效化 | 曾经异常，但因被（蓄意或意外）摧毁、失活而**不再异常**。 |
| **Explained** | 已解明 | 曾被认为异常，后被主流科学**完全解释**，或被揭穿是骗局/误会。 |
| **Decommissioned** | 已退役 | 被基金会**主动摧毁或剥离其异常性质**，通常因无法收容或代价过高（与 Neutralized 的区别在于是基金会有意为之）。 |
| **Pending** | 待定 | 尚未收集到足够信息来正确分级，强调研究仍在进行。 |
| **Uncontained** | 未收容 | 尚未被收容的异常（常为 Keter 候选），强调收容工作仍在持续。 |
| **Esoteric** | 神秘 / 自定义 | 作者为特定叙事创造的自定义等级。按惯例需被使用 25 次以上才可能被标准化收录。 |

## 三、异常分类系统 ACS（Anomaly Classification System）

**ACS** 由作者 **Woedenaz** 在社区协助下创建，是对传统 Object Class 系统的**补充而非替代**。它把单一的"收容等级"拆成多个维度，让每个异常的描述更立体。ACS 是**可选**的——作者可以自由采用、改编或忽略，许多经典条目并不使用 ACS。

ACS 由以下几部分组成，分别对应宗旨的三个词：

| ACS 组件 | 对应宗旨 | 说明 |
|---------|---------|------|
| **Clearance Level（权限等级）** | — | 标示需要多高的人员权限才能读取（Level 1 ~ Level 6） |
| **Containment Class（收容等级）** | Contain（收容） | 即旧的 Object Class：Safe / Euclid / Keter / Neutralized / Pending / Explained / Esoteric |
| **Secondary / Esoteric Class（次要/神秘等级，可选）** | — | 如 Thaumiel、Apollyon 等。ACS 把 Thaumiel 列为次要等级而非主收容等级 |
| **Disruption Class（瓦解等级）** | Secure（控制） | 衡量异常**扰乱常态、突破帷幕**的能力 |
| **Risk Class（风险等级）** | Protect（保护） | 衡量异常对**个体**的伤害严重度及恢复难易 |

### 瓦解等级（Disruption Class）

衡量异常威胁"常态/帷幕"的能力，按影响范围从小到大排列（命名取自不同程度的"光/照明"，越高级照得越广 = 扩散越广）：

| 等级 | 含义 |
|------|------|
| **Dark（暗）** | 几乎不造成扰动；不主动接触则基本惰性；基金会清理轻而易举 |
| **Vlam（焰）** | 局限于小群体；影响数人；中和相对简单 |
| **Keneq（炬）** | 城市级扩散；蔓延速度相当快；中和有一定难度 |
| **Ekhi（日）** | 影响大都会区乃至整个国家；扩散迅速、难以管控；中和相当困难 |
| **Amida（爆）** | 保留给存在级威胁；全球乃至全宇宙规模；基金会需动用一切手段 |

### 风险等级（Risk Class）

衡量异常对单个人的伤害严重度与恢复难度：

| 等级 | 含义 |
|------|------|
| **Notice（留意）** | 几乎无影响到轻微；近距离也无危险 |
| **Caution（警惕）** | 轻到中度影响；近距离有轻微危险 |
| **Warning（警告）** | 中到显著影响；近距离有中度危险 |
| **Danger（危险）** | 显著到极端影响；近距离有重大危险 |
| **Critical（危急）** | 近乎瞬时、极其严重；大概率致死；几乎无法恢复 |

## 四、站点（Sites）与区域（Areas）

基金会在全球运营大量保密设施。两类主要设施 **Site（站点）** 与 **Area（区域）** 不可混用：

| 类型 | 公众认知 | 选址 | 收容物 |
|------|---------|------|--------|
| **Site（站点）** | 公众**知道这地方存在**，但其真实用途被伪装成政府或企业建筑 | 常靠近平民聚居区 | 多为 Safe / Euclid 级等较低风险异常 |
| **Area（区域）** | 公众**完全不知道其存在**（通常因地处偏远） | 远离人口中心、隐蔽 | 多为大型、危险、敌对的高风险异常；规模通常更大，配备更重的武装 |

命名规则为 `Site-##` 与 `Area-##`（如 Site-19、Area-14）。区分主要看**公开/保密**：公开但伪装的用 Site，完全隐藏于偏远地的用 Area。

> **版本差异 / 设定模糊**：官方文档并未给出严格的编号-类型对应规则，编号大小不直接决定类型，是 Site 还是 Area 主要由"是否对公众保密"决定。

### 著名设施举例

| 设施 | 性质 | 说明 |
|------|------|------|
| **Site-19** | 站点 | **最大、最重要的运营设施之一**，收容数百个 Safe / Euclid 级异常。因异常众多、突破风险高而极重安保；同时该站员工以对低风险异常态度"过于随意"而闻名。是出现频率最高的标志性站点。 |
| **Site-7** | 站点 | 位于阿拉斯加近海，是 RAISA（记录与信息安全管理处）总部，托管 PANOPTICON 监控系统等关键基础设施。 |
| **Site-11** | 站点 | 位于密歇根州，是一个自给自足的地下社区，含居住区与地下收容设施。 |
| **Site-12** | 站点 | 位于英格兰德文郡 Avon 水坝下方，研究枢纽。 |
| **Area-14** | 区域 | 位于美国内华达州 Ruby 山脉，专门收容大型、危险、敌对的异常实体，配团级安保、重武器、装甲车与空中支援。 |
| **Area-09 / -12 / -27 / -179 / -314** | 区域 | 偏远、完全不为平民所知的隐秘设施。 |

> 部分作者也使用带特殊符号的设施编号（如 Site-Σ 数学部、Site-87 形上学/虚构学部、Site-⌘ 超现实学部），属各部门专属设施的特殊命名。

## 五、机动特遣队（Mobile Task Forces, MTF）

**机动特遣队（MTF）** 是从全基金会抽调精英人员组成的专业小队，被部署去处理**超出常规外勤人员能力或专长**的特定威胁或局势。它们代表基金会"精英中的精英（the best of the best）"。

- **命名规则**：`希腊字母 + 编号 + 昵称`，例如 MTF Alpha-1（"Red Right Hand"）、MTF Epsilon-11（"Nine-Tailed Fox"）。
- **规模差异极大**：从拥有步兵、坦克、直升机、专家的营级作战力量，到不足十人的高度专业化小队都有。
- **设立与解散**：通常由特遣队主管（Director of Task Forces）在 O5 议会批准下、为特定异常或新出现的威胁而组建；任务完成、威胁中和后多被解散，除非其专长有持续价值。

### 著名 MTF

| 代号 | 昵称（中译） | 职能 |
|------|------------|------|
| **Alpha-1** | Red Right Hand（赤红右手） | **直接向 O5 议会汇报**。执行对行动保密性要求最严苛的任务，由基金会最优秀、最忠诚的特工组成。 |
| **Epsilon-11** | **Nine-Tailed Fox（九尾狐）** | **负责基金会内部安全**。当标准协议失效、多起收容突破迫在眉睫时被部署到站点，是处理收容突破最具代表性的部队。受 Alpha-1 监督。 |
| **Nu-7** | Hammer Down（重锤落下） | 营级武装力量，含步兵、车辆、坦克、直升机及专家。应对站点的灾难性突破或失联。 |
| **Eta-10** | See No Evil（非礼勿视） | 专门处理视觉认知危害（cognitohazard）与模因（memetic）因子，需借助间接或替代观察手段。 |
| **Beta-7** | Maz Hatters（疯帽匠） | 处理极端生物、化学、放射性危害及瘟疫收容预案。 |
| **Gamma-5** | Red Herrings（红鲱鱼） | 通过记忆消除与记忆伪造，**阻止异常知识扩散**。 |
| **Mu-13** | Ghostbusters（捉鬼敢死队） | 追踪并收容无形/非实体的显现与实体。 |
| **Omega-1** | Law's Left Hand（律法左手） | **伦理委员会专属 MTF**，执行委员会政策、拘捕违反伦理的人员。（详见伦理委员会一节。） |
| **Tau-5** | Samsara（轮回） | 知名 MTF 之一（设定细节因条目而异）。 |

> **版本差异**：曾存在的 MTF **Omega-7** 在早期设定中是一支由异常实体组成的实验性特遣队，后被官方"销毁/废止"，是经典的废弃设定。不同 wiki/作者对各 MTF 的具体职能与现存状态描述常不一致。

## 六、O5 议会与管理层

### O5 议会（O5 Council / Council of Overseers / Overwatch Command）

**O5 议会** 是基金会的**最高权力机构**，又称"监督者议会"或"统辖指挥部"。

- 由 **13 名成员（O5-1 至 O5-13）** 组成，每人获任时被赋予一个数字代号。其中 O5-1 对基金会一切事务拥有绝对权威，O5-2 负责组织议会本身（具体职责分工各版本略有差异）。
- 拥有 **Level 5 安全权限**，对整个 SCP 数据库享有**无删节访问**。
- 监督全球一切行动，但**禁止直接接触任何异常项目**（防止被异常影响或腐化）。
- 全员身份高度机密，仅以数字代号识别。

### 总管 / 管理员（The Administrator）

- 在部分设定中，存在凌驾于 O5 议会之上的 **总管（The Administrator）**，持有 **Level 6（Cosmic Top Secret，宇宙级绝密）** 权限。
- **版本差异显著**：总管是否真实存在、究竟是一个人/一个职位/一个传说，各条目说法不一，常被刻意保持神秘。

### 安全权限等级（Security Clearance Levels）

权限等级标示**读取信息需要多高的授权**，与人员编级（见下）是两套不同体系：

| 等级 | 中文 | 说明 |
|------|------|------|
| **Level 0** | 仅限公开信息 | 不需知晓异常信息的非核心人员（文书、后勤、清洁） |
| **Level 1** | 保密 | 工作接近收容异常但无直接接触者 |
| **Level 2** | 受限 | 需直接接触收容中异常信息的保安与研究人员（多数研究员、外勤特工） |
| **Level 3** | 机密 | 需深入了解异常来源与长期项目的高级研究人员、项目主管、反应小组 |
| **Level 4** | 顶级机密 | 需接触站点级/区域级情报的高级管理人员（通常限站点主管） |
| **Level 5** | 绝密 / Thaumiel | 最高管理层，可随意访问一切战略与敏感数据（通常限 O5 议会） |
| **Level 6** | 宇宙级绝密 | 总管 / 极少数最高层（部分设定才有此级） |

> **版本差异**：不同 wiki 对每级权限的命名与边界（例如把 Level 5 直接叫"Thaumiel"或"Top Secret"）说法不一。上表以中文官方分部叙述为主。

### 人员编级（Personnel Classifications, Class A–E）

人员编级标示**该人员能否接触异常、若被异常影响损失有多大**，与权限等级独立：

| 编级 | 定义 |
|------|------|
| **Class A** | 对基金会**战略运营**不可或缺的人员；**禁止**直接接触异常（避免损失） |
| **Class B** | 对地方基金会运营不可或缺；仅可接触已隔离的项目 |
| **Class C** | 可直接接触不太具敌意或威胁的异常 |
| **Class D** | **可消耗人员（D 级人员）**，负责直接操作极端危险的异常，传统设定中多来自死囚；是道德争议的焦点 |
| **Class E** | 临时编级，用于外勤人员**初次接触新异常**时（在确认其精神状态稳定前的隔离观察期） |

## 七、记忆消除剂（Amnestics，A–I 级）与记忆增强剂（Mnestics，W–Z 级）

**记忆消除剂（Amnestics，旧称 "Class A/B/C amnesiacs"）** 是基金会维护帷幕的核心工具：用药物（或异常手段）抹除目击者对异常的记忆。本节依据英文主站「Updated Amnestics Guide（更新版记忆消除剂指南）」这一正典设定，它把传统的 A/B/C 三级大幅扩展。

> **版本差异**：老条目里"Class A amnestic（最强）/ Class C（最弱）"是早期粗糙设定；新指南重新定义了各级的**作用机制**（按记忆方向、靶向性区分），不再是简单的"强弱阶梯"。引用时注意条目年代。

### 记忆消除剂分级（Amnestic Classes）

| 级别 | 名称（中译） | 作用 |
|------|------------|------|
| **Class A** | 一般逆行性 | 抹除近期、特定的情节记忆，在记忆形成后 5–6 小时内最有效；可针对单一记忆（如异常遭遇），并能重开"记忆再固化窗口"以延迟抹除 |
| **Class B** | 渐退逆行性 | 从**最近**形成的记忆开始去固化，逐步往前推。约 75mg 通常抹除约 24 小时记忆，适合处理超出 6 小时窗口的近期事件 |
| **Class C** | 靶向逆行性 | **外科级精确**抹除任意时间点的特定记忆，需神经成像与经颅刺激定位记忆痕迹；最适合在站点内操作，尤其用于释放 D 级人员或类人型 SCP 前 |
| **Class D** | 渐进逆行性 | 与 B 相反，从**最老**记忆开始往后抹；需极高剂量、副作用风险大，应用极窄；保留隐性记忆（已习得技能） |
| **Class E** | 倦怠（Ennui） | 不直接抹除记忆，而是削弱神经通路、情感上剥离记忆，使其自然衰退；如"反怀旧"，让对象把异常视为**正常**而非将其遗忘 |
| **Class F** | 神游（Fugue） | 诱发分离性失忆、丧失自我身份；对象可被赋予替换身份或自行重建新身份 |
| **Class G** | 煤气灯（Gaslighting） | 诱发现实感丧失，使记忆变得像梦境般可疑；标准版仅针对异常记忆，非异常用途被伦理委员会禁止 |
| **Class H** | 顺行性 | 阻断记忆固化，**阻止新记忆形成**；持续时间随剂量，75mg 约持续 24 小时 |
| **Class I** | 短暂性 | 通过阻断长期记忆神经通路诱发**临时性**失忆，效果类似 Class H |

### 记忆增强剂（Mnestics，W–Z 级）

**记忆增强剂（Mnestics）** 与记忆消除剂作用相反，用于**强化记忆/对抗遗忘**，尤其用于研究"反模因（antimemes，自我隐藏、令人忘记的概念）"——因为有些异常**只能在记得它的时候**才能被对抗。

| 级别 | 作用 |
|------|------|
| **Class W** | 增强对反模因知识的感知与保持 |
| **Class X** | 试图实现永葆青春的血清，伴有危险的"反弹（whiplash）"副作用 |
| **Class Y** | 在药效期内实现完美回忆 |
| **Class Z** | 在生化层面**永久无法遗忘**；几乎必然在数小时内致死 |

> **关联设定**：记忆增强剂是「反模因部门（Antimemetics Division）」系列故事的核心道具（如名作《There Is No Antimemetics Division》），Class Z 的致命性是该系列的关键张力来源。

## 八、K 级情景（K-Class Scenarios，世界末日情景）

**K 级情景（K-Class Scenario）** 指**可能对常态或现实造成剧烈影响、乃至世界终结的假想情境**。基金会为这些事件制定应急预案，作者也常在作品中引用。

> **重要原则（官方明确声明）**：K 级情景**没有正典定义**——所有定义都来自各条目的**实际使用习惯**，而非被规定死。因此同一前缀在不同作者笔下含义可能不同。Apollyon 级项目往往与某种即将发生的 K 级情景挂钩。

### 主要 K 级情景类型

| 前缀 | 名称（中译） | 定义 |
|------|------------|------|
| **XK** | 世界末日（End-of-the-World） | **最广义、最常用**的一类，涵盖几乎任何末日：宗教末日、人类灭绝、地球毁灭、宇宙湮灭。被用于超过百个 SCP 与大量故事 |
| **ZK** | 现实失效 / 现实崩溃（Reality Failure） | 现实从根本上被打破或消除，通常因物理性异常或本质上"会湮灭一切"的项目；有时局限于特定区域 |
| **CK** | 现实重构（Reality Restructuring） | 现实被某神祇/现实扭曲者/逆因果手段改写，从剧变到微调皆有；部分用法与 RK 级互换 |
| **TK** | 因果重构（时间线重构） | 在重大现实改写后，时间线被打破又被修复，但像修补的花瓶一样存在裂痕——事件对不上、出现无因之果 |
| **ΩK（Omega-K）** | 终末之死（End-of-Death） | 不死被强加于一切生命（无其他生物学改变），可能因人口爆炸导致社会崩溃 |
| **NK** | 灰蛊 / 灰色黏质（Grey Goo） | 自我复制的 SCP 失控繁殖，用自身填满或替换整个世界 |
| **SK** | 支配权转移（Dominance Shift） | 另一物种取代人类成为优势物种，或反之，根本改变行星层级 |
| **HK** | 神性奴役（Deific Subjugation） | 某神祇降临并接管人类与文明 |
| **AK** | 疯狂（Madness） | 模因式扩散的行为引发末日级疯狂，或社会被迫围绕该行为重组 |
| **IK** | 文明崩溃（Civilization Collapse） | 文明瓦解、社会崩坏，但不必然消灭人类 |
| **LK** | 物种嬗变（Species Transmutation） | 人类的根本本质发生转化或改变 |
| **EK** | 人类意识终结 | 因模因替换或腐化导致人类意识的彻底丧失 |
| **GK / GH** | 死寂温室（Dead Greenhouse） | 人类濒危或灭绝，但地球对其他生命仍宜居 |
| **PK** | 超现实意识崩溃 | 引发叙事性湮灭（与"现实即虚构"的形上学设定相关） |
| **WK** | 非人物种灭绝 | 针对非人类物种的灭绝事件 |
| **YK** | 物理性末日 | 基于物理规律崩坏的末日 |
| **QK** | 量子简并末日 | 基于量子简并的终结情景 |

此外还有两类与"帷幕"直接相关的特殊情景：

- **Lifted Veil（帷幕揭起）/ Broken Masquerade（假面破碎）**：基金会或异常的存在变为公众知识——即帷幕被永久揭开。这是无数衍生设定（"Broken Masquerade"系列正典）的起点，本质上是一种社会层面的末日。

## 九、部门与机构（Departments & Divisions）

基金会内部按职能划分为大量部门与处室。除前述 O5 议会、伦理委员会、MTF 外，下面按类别列举主要机构。

> 不同 wiki/语言分部对部门的命名、归属、是否存在差异很大；许多部门是单一作者为某系列创作的，并非"全基金会公认"。这是典型的**版本/作者差异**领域。

### 行政与监督机构

| 机构 | 职能 |
|------|------|
| **O5 议会（O5 Council）** | 最高决策机构，决定"什么是安全的、该怎么做"。详见第六节 |
| **伦理委员会（Ethics Committee）** | 与 O5 互补：O5 决定"什么是安全的"，**伦理委员会决定"什么是合乎伦理的"**。基金会作风务实冷酷，但伦理委员会确保只做**必要的**牺牲、尽量选择最合乎伦理的方案。它拥有专属 MTF **Omega-1（Law's Left Hand）** 来执行政策、拘捕违规人员 |
| **RAISA（记录与信息安全管理处）** | 维护数据库安全、控制机密访问权限、管理备份，并监控文件异常变动（防止异常篡改档案） |

### 主要运营 / 研究部门

| 部门 | 职能 |
|------|------|
| **科学 / 研究部门（Scientific / Research Dept.）** | 对 SCP（含有感知与无感知对象）进行异常实验、记录结果。是仅次于安保部门的第二大部门 |
| **安保部门（Security Dept.）** | 站点安保、收容突破响应。是最大的部门 |
| **内部安全部（Internal Security Dept.）** | 防范内部渗透、叛变、间谍 |
| **情报局（Intelligence Agency）** | 情报搜集与反情报 |
| **医疗部门（Medical Dept.）** | 人员与异常实体的医疗 |
| **工程与技术服务部（Engineering & Technical Services, ETSD）** | 建造、维护收容设施与设备 |
| **后勤部门（Logistics Dept.）** | 物资调配 |
| **制造部门（Manufacturing Dept.）** | 生产基金会所需物资 |
| **外务部 / 对外事务部（Dept. of External Affairs）** | 与各国政府、相关组织（GoI）周旋 |
| **退役部门（Decommissioning Dept.）** | 审议并执行对"过于危险、不可预测或耗资过巨"异常的退役（销毁/剥离异常性）提案 |

### 专业研究分部（多为特定系列设定）

| 部门 | 职能 |
|------|------|
| **反模因部门（Antimemetics Division）** | 研究反模因——具自我审查性、阻止人传播或令人遗忘的概念。是热门正典系列的核心 |
| **形上学 / 虚构学部（Pataphysics Department）** | 研究"叙事异常"以及"现实本身即虚构"的情况，驻 Site-87 |
| **战术神学部（Dept. of Tactical Theology）** | 捕获、收容神学异常、圣物及超自然教派 |
| **时间异常部（Temporal Anomalies Dept. / Delta-T）** | 处理逆因果、反历史异常 |
| **误传部 / 错误通信部（Dept. of Miscommunications）** | 处理操纵语言、使其难以被准确描述与收容的异常 |
| **炼金术部（Alchemy Dept.）** | 当常规科学失效时，研究构成现实基本元素的"以太力" |
| **人工智能应用部（AIAD）** | 开发 AI 系统、收容异常智能体 |
| **隐生物学部 / 神秘动物部（Cryptozoology Division）** | 处理隐生物（cryptid）类异常，驻 Site-44 |
| **数学部（Dept. of Mathematics）** | 研究影响"自然界逻辑基础"的数学异常，驻 Site-Σ |
| **超现实学部（Dept. of Surrealistics）** | 处理无法用传统逻辑理解的异常，驻 Site-⌘ |
| **异常武器开发部（AWD）** | 为 MTF 与站点安保设计、生产副物理/本征武器 |
| **新兴威胁战术响应局（ETTRA）** | 协调对多站点/全球性威胁的紧急响应 |
| **其它部（Dept. of Other）** | 收容玩笑类异常及不归属任何其他部门的条目 |

> 设定中还存在大量风格化/半玩笑的机构，如作为掩护资金来源的前台公司"Spicy Crust Pizzeria（辣皮披萨店）"、关注员工身心健康的"消防部门（Fire Suppression Dept.）"、"采购与清算部"、"电信监听办公室（TMO）"等，体现 SCP 设定的广度与社区幽默感。

## 十、小结：互相联系的机制网

把上述机制串起来理解基金会的运转逻辑：

1. **发现异常** → 评估其**收容难度**（Object/Containment Class：Safe/Euclid/Keter…）和（用 ACS 时）**瓦解能力 + 个体风险**；
2. **收容** → 关进合适的 **Site/Area**，按 ACS 写明收容措施；难缠的派 **MTF**（如九尾狐处理突破）；
3. **维护帷幕** → 对目击者用 **记忆消除剂（Amnestics）**，让世界继续相信"常态"；
4. **管控人员** → 用**权限等级**控制谁能看什么，用**人员编级**控制谁能接触异常（D 级去送死）；
5. **顶层决策** → **O5 议会**拍板"安全与否"，**伦理委员会**把关"伦理与否"；
6. **最坏情况** → 一旦异常将引发 **K 级情景**（XK/CK/ZK…），它可能被定为 **Apollyon** 级，基金会启动末日预案。

整套机制的终极目的只有一个：**让你继续相信，世界是正常的。**
