# 后室 × SCP 基金会 · 本地中文知识库

> 一个把 **后室（The Backrooms）** 与 **SCP 基金会（SCP Foundation）** 两大网络都市传说世界观整理在一起的本地中文知识库，外加一条可玩的故事线。所有条目均基于真实社区 wiki（Wikidot 新版 / Fandom 旧版 / 中文分部）实地调研撰写，逐条标注版本差异，术语保留英文原名并附中译。

## 🎮 可玩游戏《后室·无尽回廊》

在知识库之上做了一款**单文件离线网页文字生存游戏 / 互动小说**。

- **直接玩**：双击 [`游戏/后室-无尽回廊.html`](游戏/后室-无尽回廊.html)，浏览器打开即可。零依赖、离线、无需安装。

## 1. 项目简介

本仓库是一个 **后室 + SCP 基金会的本地中文知识库 + 可玩故事线**。

- **知识库部分**：把两套世界观的核心设定、层级 / 条目、实体 / 异常、组织 / 关注组织、物品 / 资源、正史 / Canon 体系系统性地整理成结构化中文文档，方便离线检索、写作取材与跑团参考。
- **故事线部分**：在知识库之上构建一条可玩的主故事线（`STORYLINE.md`）与若干探险叙事，把分散的设定串成可被「走进去」的剧情，让读者既能查资料，也能沉浸式体验。

两个世界**同源但独立**：均发端于 4chan /x/ 板的社区创作，后室借鉴了 SCP 的协作百科模式与「阈限空间」母题（尤其 SCP-3008 无限宜家），但二者并无官方交叉正史，「基金会收容后室」一类属于二次创作。详见 [后室·渊源与发展史](后室/00-起源与发展史.md) 与 [后室·与 SCP 的关系](后室/00-渊源-与SCP的关系.md)。

> 调研方法：以 Wikidot 官方新版为最权威基准，Fandom 旧版 / Miraheze / 中文社区交叉印证；同编号设定冲突一律标注「版本差异」，主流 wiki 中查无对应者按「不编造」原则如实说明，不杜撰。

## 4. 阅读建议

不熟悉这两个世界的新读者，推荐按下面的顺序逐步深入：

1. **先读起源**：[后室·起源与发展史](后室/00-起源与发展史.md) → [后室·与 SCP 的关系](后室/00-渊源-与SCP的关系.md)。先搞清两个世界从哪来、怎么分家，再看具体设定不会混乱。SCP 一侧可配 [SCP·世界观与机制](SCP基金会/00-世界观与机制.md) 建立收容等级 / 帷幕等基础概念。
2. **进入 Level 0**：从 [Level 0 阈界（黄房间）](后室/层级/Level-0-阈界（黄房间）.md) 开始——这是整个后室的「玄关」，也是最经典的发黄房间意象。然后顺着出口往 [Level 1](后室/层级/Level-1-宜居地带.md)、[Level 2](后室/层级/Level-2-废弃公共带.md) 往下逛，配合 [层级总表](后室/层级/00-层级总表.md) 鸟瞰全貌。
3. **认识同行者与威胁**：读到层级里出现的实体 / 组织时，回到 [实体](#34-后室--实体共-16-篇) 与 [组织](#35-后室--组织共-9-篇--总览--考据) 章节查档，并随身备好 [杏仁水](后室/物品/01-杏仁水-Almond-Water.md) 这类基础知识。
4. **主故事线**：在掌握基础设定后，进入 `STORYLINE.md`（规划中）体验把这些设定串起来的主线剧情。
5. **探险叙事**：最后读各篇探险叙事（规划中），以沉浸式视角重走那些层级，把「资料」变成「经历」。

SCP 一侧可独立阅读：从 [SCP·条目总表](SCP基金会/条目/00-条目总表.md) 挑感兴趣的条目（如 [SCP-173](SCP基金会/条目/SCP-173-雕塑.md)、[SCP-096](SCP基金会/条目/SCP-096-害羞的人.md)、[SCP-3008](SCP基金会/条目/SCP-3008-无限IKEA.md)），再用 [Canon 世界线](SCP基金会/Canon-世界线.md) 理解「没有单一正史」的阅读方式。
